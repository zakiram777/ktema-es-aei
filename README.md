# Κτῆμα ἐς Ἀεί

시세와 차트를 보고, 견주고, 적어 두고, 시험한다.

> *κτῆμα ἐς αἰεὶ μᾶλλον ἢ ἀγώνισμα ἐς τὸ παραχρῆμα ἀκούειν*
> — 투키디데스 『펠로폰네소스 전쟁사』 I.22

빌드 도구가 필요 없는 순수 정적 사이트다. 파일을 그대로 올리면 돌아간다.

## 1. 올리기

이 폴더의 내용을 **통째로** 웹 공간의 최상위(`public_html`, `www`, `htdocs` 등)에 올린다.

```
index.html
.htaccess
api/proxy.php
assets/
```

아래는 미리보기·문서용이라 올리지 않아도 된다. 올려도 아무 일도 하지 않는다.

```
SETUP.bat  START.bat  start.sh  serve.mjs  setup.mjs
NODE-REQUIRED.txt  시작하기.txt  README.md  nginx.conf.example
```

`http://내도메인/` 으로 들어가면 관문이 뜬다. **오늘 날짜의 월일 넉 자**를
넣으면 열린다 — 8월 27일이면 `0827`, 12월 12일이면 `1212`.

> 이것은 자물쇠가 아니다. 답이 달력에 적혀 있으니 들어오려는 자를 막지
> 못한다. 막을 셈이었다면 서버가 있어야 하고, 이 사이트에는 서버가 없다.
> 이것은 문턱이다 — 오늘을 알고 온 이에게 열리는. 그리고 브라우저가 소리를
> 내려면 사람의 첫 누름이 필요한데, 그 누름을 받는 자리이기도 하다.
> 날짜는 보는 사람의 기기 시각으로 센다.

> **ES 모듈을 쓰므로 웹서버가 있어야 한다.** `index.html` 을 두 번 눌러
> `file://` 로 여는 방식으로는 뜨지 않는다. 내 컴퓨터에서 먼저 보려면
> 아래 2장을 보라.

## 1-2. 다른 PC 에서 이어서 하기

이 폴더는 **어느 컴퓨터에 갖다 놓아도 그대로 돈다.** 설치할 꾸러미도,
빌드도, 이 컴퓨터에만 있는 경로도 없다. 폴더만 옮기면 끝이다.

### 처음 한 번 — `SETUP.bat`

두 번 누르면 알아서 다 한다.

1. **Node.js 가 없으면 설치할지 묻고 자동으로 깐다** (`winget` 이용).
   winget 이 없으면 [nodejs.org](https://nodejs.org) 를 열어 준다
2. 파일이 온전한지 검사한다 (영상 열세 편까지)
3. `settings.json` 이 있으면 찾아내 알려 준다
4. 바탕화면 바로가기를 만들지 묻는다
5. 사이트를 띄우고 브라우저를 연다

맥·리눅스는 `./start.sh`.

### 그 다음부터 — `START.bat`

| | |
|---|---|
| **윈도우** | `START.bat` 또는 바탕화면 바로가기 |
| **맥 · 리눅스** | `./start.sh` |
| **직접** | `node serve.mjs --open` |

4488 번 문이 이미 쓰이고 있으면 알아서 옆 번호로 옮긴다.

> 배치파일 안에는 한글을 한 자도 넣지 않았다. PC 마다 콘솔 코드페이지가
> 달라 깨지기 때문이다. 사람에게 하는 말은 전부 `setup.mjs`(Node)가 한다.

### 휴대폰이나 옆자리 PC 에서 보기

같은 공유기에 물려 있다면 이 PC 를 켜 둔 채로 볼 수 있다.

```bash
node serve.mjs --lan
```

띄우면 `http://192.168.x.x:4488` 같은 주소를 알려 준다. 그 주소를 다른
기기에 치면 된다. 창을 닫으면 꺼진다.

> 기본값은 이 컴퓨터 안에서만 열린다. `--lan` 을 줄 때만 바깥으로 연다.

### 이 PC 없이 쓰려면

위의 방법들은 모두 **이 PC 가 켜져 있어야** 한다. 아예 떼어 놓으려면
둘 중 하나다.

**ㄱ. 웹호스팅에 올린다 (보기 전용)**
1장대로 올리면 인터넷 주소가 생긴다. 그 뒤로는 아무 기기에서나
주소만 치면 되고, 이 PC 는 꺼져 있어도 된다.

**ㄴ. 폴더를 들고 다닌다 (고치기까지)**
`ktema` 폴더째 아래 어디든 두면, 다른 PC 에서 받아 그대로 이어서 고칠 수
있다.

* **OneDrive · Google Drive · Dropbox** — 폴더를 그 안에 두면 저절로 따라온다.
  가장 손이 덜 간다
* **Git** (GitHub 등) — 고친 내력이 남고 되돌리기 쉽다. 여러 PC 를 오갈
  거라면 이쪽이 낫다
* **USB** — 그냥 복사하면 된다. 영상까지 23MB 다

어느 쪽이든 받은 PC 에서 `START.bat` 만 누르면 똑같이 뜬다.

### 설정도 같이 옮기기

설정은 서버가 아니라 **브라우저**에 남는다. 그래서 폴더를 옮겨도 만들어 둔
지표도 관심종목도 따라오지 않는다. 파일 한 장으로 옮긴다.

**전에 쓰던 PC** — 설정 → *Περί* 이 사이트 → **설정 내보내기**
→ `settings.json` 이 받아진다.

**새 PC** — 그 파일을 `index.html` 옆에 놓기만 하면 된다.
켤 때 **저절로 적용된다.** 아무것도 누르지 않아도 된다.

```
ktema/
  index.html
  settings.json   ← 여기
  assets/
```

관심종목·만들어 둔 지표·전략·오르내림 색·출처 켜고 끄기·갱신 간격·속보·
차트 기간이 모두 넘어간다. 읽은 기사 목록과 투자일지는 담지 않는다 —
일지는 일지 화면에서 따로 내보낸다.

한 번 적용하면 그 파일은 다시 심지 않는다. 새 PC 에서 취향을 바꿔도
다음에 켤 때 되돌아가지 않는다는 뜻이다. 설정을 새로 내보내 파일을
갈아 끼우면 (`savedAt` 이 달라지므로) 그때 다시 적용된다.

파일을 폴더에 넣기 번거로우면 설정 화면의 **설정 가져오기** 로 직접
골라도 똑같다.

> 웹호스팅에 올릴 때 `settings.json` 을 같이 올리면 **그 사이트에 처음
> 들어오는 모든 사람**에게 그 설정이 심긴다. 혼자 쓸 것이 아니라면
> 올리지 않는 편이 낫다.

> `serve.mjs`·`START.bat`·`start.sh` 는 미리보기 전용이다.
> 웹호스팅에 올릴 때는 아무 일도 하지 않으니 지워도 된다.

### 호스팅 종류별로

| 호스팅 | 할 일 |
|---|---|
| **일반 웹호스팅 (Apache)** | 그대로 올린다. `.htaccess` 가 알아서 맞춘다. PHP 가 되면 `api/proxy.php` 도 같이 살아난다 |
| **Nginx** | `.htaccess` 는 무시된다. `nginx.conf.example` 의 내용을 서버 설정에 옮긴다 |
| **Vercel / Netlify / GitHub Pages** | 폴더째 올리면 된다. PHP 는 돌지 않으므로 공개 프록시를 쓴다 |
| **PHP 없는 정적 호스팅** | `api/` 를 지워도 된다. 사이트가 알아서 공개 프록시로 넘어간다 |

### 용량

영상 열세 편이 약 23MB, 나머지가 1MB 미만이다. 영상은 필요할 때 한 편씩
받고, 나머지는 화면이 뜬 뒤 조용히 받아 둔다. 첫 화면에 필요한 것은 1.6MB
한 편뿐이다.

## 2. 소식은 어디서 오나

각 언론사가 스스로 열어 둔 **공개 RSS** 다. 목록은
[`assets/js/news/sources.js`](assets/js/news/sources.js) 한 곳에 있다.

한국어 — 연합뉴스, 한국경제, 매일경제, 이데일리, 조선비즈, 동아일보, 한겨레
영어 — Yahoo Finance, MarketWatch, WSJ Markets, Financial Times,
Investing.com, Seeking Alpha, Federal Reserve

출처를 더하려면 그 파일의 `SOURCES` 에 한 줄 보태면 된다.

```js
{
  id: 'my-source',            // 안에서만 쓰는 이름표 (바꾸지 말 것)
  name: '내 언론사',            // 화면에 뜨는 이름
  lang: 'ko',                 // ko | en
  weight: 6,                  // 같은 기사가 겹칠 때 누구를 남길지
  url: 'https://…/rss.xml',
  cats: ['econ', 'stock'],    // all·stock·econ·invest·world
}
```

PHP 프록시를 쓰고 있다면 `api/proxy.php` 의 `ALLOW` 에도 그 도메인을 적어야
한다. 적지 않으면 그 출처만 막힌다.

### CORS 를 넘는 방법

브라우저는 남의 도메인에서 RSS 를 곧바로 받아 오지 못한다. 그래서 길을
여럿 두고, 먼저 열리는 길을 그 출처의 길로 기억한다.

```
0. api/proxy.php        이 사이트에 있으면 가장 먼저, 가장 안정적
1. 곧바로                CORS 를 열어 둔 곳 (MarketWatch, Yahoo 뉴스 RSS)
2. 공개 프록시 다섯 곳     나머지 전부
   cors.sh · corsfix · cors.eu.org · allorigins · codetabs
```

설정 → *Περί* 에서 지금 어느 길로 다니고 있는지 볼 수 있다.

> **공개 프록시는 오래 두면 하나씩 문을 닫는다.** 2026년 8월에 다시 두드려
> 보고 목록을 갈아 끼웠다 — corsproxy.io 는 열쇠를 요구하게 되었고,
> api.cors.lol 은 응답하지 않는다. 야후 시세(`query1.finance.yahoo.com`)도
> 예전과 달리 CORS 를 닫아, 이제는 시세도 프록시를 거친다.
>
> 언젠가 이 다섯도 다 막힐 수 있다. 그때는
> [`assets/js/net/proxy.js`](assets/js/net/proxy.js) 의 `ROUTES` 에 살아
> 있는 곳을 한 줄 보태면 된다. 애초에 그런 날을 위해 `api/proxy.php` 가
> 있다 — PHP 가 되는 호스팅에 올려 두면 남의 호의에 기대지 않는다.
>
> 길은 출처마다 따로 배운다. 어떤 프록시는 되돌림(redirect)을 제대로
> 따라가지 못해 한겨레·FT 처럼 주소를 옮기는 곳에서만 넘어지는데, 그런
> 곳은 다음 길이 받아 준다. 그래서 길을 여럿 둔다.

## 2-2. 화면의 짜임

시세를 보는 화면은 대개 같은 모양이다. 위에 띠 하나, 왼쪽에 좁은 메뉴,
가운데에 가장 큰 것(차트), 오른쪽에 지켜보는 목록. TradingView 를
참고했지만 값을 베끼지는 않았다. **그 화면이 왜 그렇게 생겼는지**를
가져왔다.

| 자리 | 무엇이 | 왜 거기 |
|---|---|---|
| 머리띠 | 종목 고르개 · 기간 · 시계 | 가장 자주 하는 일이다. 화면을 옮겨도 그 자리는 움직이지 않는다 |
| 왼쪽 띠 | 여섯 화면 | 화면 갈아 끼우기는 자주 하는 일이 아니다. 좁게 둔다 |
| 가운데 | 차트 · 시세 · 분석 · 소식 · 일지 · 시험 | 남는 자리를 전부 먹는다 |
| 오른쪽 | 관심종목 | 차트를 보다가 다른 것이 움직이면 곁눈으로 알아채야 한다 |

자리는 **쓰는 횟수에 비례해** 준다.

### 왜 다시 어두운가

한때 이 사이트는 흰 종이였다. 그때는 그림이 주인공이었으니 그래도 됐다.
지금 주인공은 숫자다.

* 흰 바탕에 검은 숫자는 종이에서는 좋지만 화면에서는 눈이 빨리 지친다
* 값이 붉음과 푸름으로 갈리는 화면이라면 더 그렇다 — 흰 바탕에서는 두
  색이 다 떠 보이고, 어두운 바탕에서는 둘 다 가라앉아 제자리에 있는다
* 바탕은 검정이 아니라 아주 어두운 남색(`#0b0e14`)이다. 순검정은 화면에
  구멍처럼 보이고, 그 위의 흰 글씨는 번진다

| | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#0b0e14` … `#3a4358` | 판과 판은 **선이 아니라 밝기 한 칸**으로 가른다 |
| 글자 | `#e6ebf2` … `#5a6478` | 값이 가장 또렷하고, 곁말이 흐리다 |
| 강조 | `#2962ff` 파랑 **하나** | 고른 것 · 누를 것 |
| 오름·내림 | `#f0554d` · `#3f8ae0` | 설정에서 세계 관행(오름 초록)으로 뒤집는다 |
| 모서리 | 2 – 6px | 도구는 둥글지 않다 |

숫자는 폭이 고정된 글꼴(IBM Plex Mono)에 `tabular-nums` 를 건다. 값이
바뀔 때 자리가 흔들리면 읽는 사람이 매번 눈으로 다시 찾는다.

색은 [`tokens.css`](assets/css/tokens.css) 한 곳에 있다. 옛 이름들
(`--gold-400` 같은 것)은 지우지 않고 새 쪽으로 다시 걸어 두었다 —
여기저기 흩어진 자리를 한 번에 뒤집기 위해서다.

## 3. 배경 — 이토 준지

사람은 걷어 냈지만 그림은 남겼다. 도구는 도구인데, 아무 도구나 되고
싶지는 않았다.

원본은 `C:\Jhihong\itojunji` 의 넉 장이다. 격자로 늘어놓은 영상 둘은
셀마다 잘라 스물넷으로 폈다.

```
ito2.mp4  768×1168  전신          →  full.mp4
ito3.mp4  944×944   4열 3행 격자  →  calm-01 … calm-12   (바탕에 쓴다)
ito4.mp4  944×944   3열 4행 격자  →  wild-01 … wild-12   (관문에 쓴다)
```

> 격자를 자를 때 셀 높이가 315였다. `yuv420p` 는 짝수만 받으므로 열두
> 편이 조용히 0바이트로 나왔다. 314로 깎아 다시 떴다.

### 얼마나 보여야 하나

숫자를 읽는 화면이다. 배경이 보이면 그만큼 못 읽는다. 그런데 아주 안
보이면 왜 넣었나 싶어진다. **무엇인지 알아보기 직전**에서 멈춘다 —
알아보게 되면 그때부터 그것만 보이기 때문이다.

| 겹 | 무엇 | 짙기 |
|---|---|---|
| `film` | ink 영상 하나. 40여 초에 한 번 갈린다 | `.085`, 26px 흐림 |
| `wash` | 가운데를 눌러 어둡게, 가장자리만 조금 열어 둔다 | — |
| `grid` | 시세 화면의 눈금. 아주 느리게 흐른다 (canvas) | `.028` |
| `grain` | 종이 결. 색 띠가 계단처럼 보이는 것을 흩어 준다 | `.16` |

바탕에는 **잔잔한 쪽(calm)만** 쓴다. 관문에서는 반대다 — 한 번만 보는
화면이므로 세게 때려도 되고, 거기서는 그림이 주인공이다. 격한 쪽(wild)을
쓰고 흐리지 않는다. 들어오고 나면 다시 없다.

설정 → *Ὄψις* 에서 배경의 움직임을 끌 수 있다.

## 4. 유리아 — 부를 때만 온다

배경의 그림과 같은 먹에서 나왔다. 다만 배경은 늘 흐르고, 이쪽은
**부를 일이 있을 때만** 한 번 나타났다 사라진다.

### 종이를 오려 냈다

원본은 흰 종이에 그린 먹이다. 그대로 얹으면 흰 종이가 네모로 뜬다.
그러면 *사람이 나타난 것*이 아니라 *그림이 뜬 것*이 되고, 그 순간 이
장치가 하려던 일이 통째로 무너진다. 놀라게 하려고 부르는데 판이 먼저
보이면 놀랄 일이 없다.

그래서 SVG 필터로 진짜로 오려 냈다 ([`index.html`](index.html) 의
`#yuriaCut`). 밝기를 뒤집어 알파로 삼으면 먹만 남고 종이는 비어 버린다.

```
알파 = 1 − (0.299R + 0.587G + 0.114B)
색   = 옅은 청백 고정 (185,198,218)
```

배경이 어두우므로 색은 먹빛이 아니라 청백으로 칠한다 — 어두운 바탕에
흰 선으로 그린 그림이 되는 셈이다. 재어 보면 네 귀퉁이 알파가 모두
`0.0000`, 가운데는 `1.000`, 남는 넓이는 `49.6%` 다. 판도 테두리도
그늘도 없다. 글자는 그림 곁에 그냥 떠 있고 뒤에는 아주 옅은 빛만 깐다
— 상자를 두면 그 상자가 다시 네모가 되기 때문이다.

> 잔잔한 쪽은 세로 236×314, 격한 쪽은 가로 314×236 이다. 격자를 자를 때
> 행과 열이 달랐던 탓인데(§3 참조), 한 틀에 우겨 넣으면 `cover` 가 옆을
> 잘라 사람이 반쪽이 된다. 틀을 그림에 맞췄다 (`.yuria__art.is-wide`).

### 부를 일 넷

**스스로는 나타나지 않는다.** 이 규칙이 깨지면 그 다음부터는 아무도
쳐다보지 않는다.

| | 언제 | 그림 | 다시 부르기까지 |
|---|---|---|---|
| `surge` | 시장이 갑자기 크게 움직였다 | 격한 쪽 | 1시간 |
| `rule` | 걸어 둔 규칙이 **오늘** 걸렸다 | 잔잔한 쪽 | 12시간 |
| `filing` | 급한 공시 (점수 9 이상만) | 격한 쪽 | 6시간 |
| `open` | 하루의 첫 방문 — 간밤에 무슨 일이 있었나 | 잔잔한 쪽 | 20시간 |

`surge` 는 등락률이 아니라 **그 종목의 평소 흔들림으로 나눠** 잰다
(σ). 고정 퍼센트로 잡으면 비트코인은 하루가 멀다 하고 걸리고 채권은
영영 안 걸린다. 그것은 소식이 아니라 그 종목의 성격일 뿐이다.

`rule` 이 **오늘** 걸린 것만 알리는 것도 같은 이유다. 어제 걸린 것을
알리는 것은 알림이 아니라 회고이고, 그것은 일지 화면이 할 일이다.

`open` 의 '하루 한 번' 은 반드시 지켜져야 성립한다. 두 번째부터는
안내가 아니라 잔소리다.

## 6. 시세와 차트

야후 파이낸스만 쓴다. 등록도 열쇠도 필요 없다. 문은 둘이다.

| 문 | 언제 | 무엇이 오나 |
|---|---|---|
| `spark` | 시세판을 채울 때 — **열둘을 한 번에** | 종가 줄과 그 앞 종가 |
| `chart` | 차트 하나를 그릴 때 | 시가·고가·저가·종가·거래량·52주 |

시세판을 종목마다 한 번씩 부르면 첫 화면에서만 서른 번 남짓 프록시를
두드리게 된다. 남의 프록시는 대개 "몇 초에 몇 번" 으로 문턱을 세므로,
그 셈이 차는 순간 마지막에 나간 차트만 홀로 넘어진다 — *소식은 오는데
차트만 안 뜬다* 는 모양이 그것이었다. 그래서 시세판은 `spark` 로 한 번에
묻고, 소식도 [`pool.js`](assets/js/core/pool.js) 로 여섯씩 줄을 세운다.
`spark` 가 막히면 예전처럼 하나씩 묻는 길로 조용히 되돌아간다.

### 굴려서 들여다보기

차트에 손을 얹고 굴리면 **손끝이 얹힌 자리를 붙든 채** 창이 좁아지거나
넓어진다. 가운데를 기준으로 하면 보려던 것이 자꾸 화면 밖으로 밀려난다.

| | |
|---|---|
| 굴리기 | 당기고 민다 (봉 열두 개까지 좁힐 수 있다) |
| 끌기 | 옆으로 흐른다 — 종이를 미는 것과 같은 방향 |
| 두 번 누르기 | 받아 온 것 전부로 되돌린다 |

기간 단추(5일·1개월…)는 서버에 다시 묻는 일이고, 이것은 이미 받아 둔
봉 안에서 들여다보는 일이다. 둘은 다르다 — 5년치를 받아 놓고 그 안의
한 달을 확대해 볼 수 있다.

> **지표는 늘 전체 봉으로 셈한다.** 보이는 구간만으로 셈하면 창 왼쪽
> 끝의 예순 날 평균이 틀린다 — 그 앞 예순 날이 없으니까. 셈은 전체로
> 하고, 그린 줄에서 보이는 자리만 오려 낸다.

차트 아래 한 줄에는 **눈으로는 안 보이는 것만** 적는다 — 얼마나 흔들렸나,
꼭대기에서 얼마나 팠나, 한 해 폭 어디쯤인가. 시가·고가 같은 것은 차트를
보면 알므로 뒤로 민다.

### 무엇을 볼 것인가

머리띠의 고르개(`/` 키)에서 **이름으로 찾는다.** 기호를 외우고 있는
사람은 없다.

* 기호를 안다면 `005930.KS` 를 그대로 적고 Enter
* 이름만 안다면 "삼성" 이라고 적으면 야후에 물어본다
* 아무것도 모른다면 자주 보는 것들이 처음부터 놓여 있다

> 한 글자 칠 때마다 밖에 묻지 않는다. 손이 멎고 나서 260밀리초 뒤에 한 번
> 묻는다. 공개 프록시에는 문턱이 있고, "삼성전자" 를 치는 동안 다섯 번
> 물으면 그 문턱에 걸린다.

오른쪽 관심종목은 `+` 로 더하고 `×` 로 뺀다. 하나도 남지 않으면 다음에
켤 때 처음 목록이 되살아난다 — 텅 빈 칸을 보여 주는 것보다 낫다. 처음
목록은 [`symbols.js`](assets/js/market/symbols.js) 의 `DEFAULT_WATCH` 다.

> 시세는 지연될 수 있고 참고용이다. 이 사이트의 어떤 숫자도 사거나 팔라는
> 말이 아니다.

## 6-2. 지표를 만든다

차트에 얹는 줄은 정해져 있지 않다. 틀을 고르고 기간만 정하면 새 지표가
된다. 같은 틀로 여럿 만들 수 있다 — 이동평균 20일과 112일은 다른 지표다.

차트 화면의 **지표** 단추를 누르면 서랍이 펴진다.

| 틀 | 어디에 | 무엇 |
|---|---|---|
| **이동평균** Μέσος | 봉 위에 겹쳐 | 정해진 날수의 종가 평균 |
| **지수이동평균** Ἐκθετικός | 봉 위에 겹쳐 | 최근 값에 더 무게를 준 평균 |
| **볼린저 밴드** Ζώνη | 봉 위에 겹쳐 | 평균에서 표준편차만큼 떨어진 두 줄 |
| **상대강도** Ἰσχύς | 아래 칸에 따로 | 0~100. 오른 날의 힘과 내린 날의 힘 |
| **MACD** Σύγκλισις | 아래 칸에 따로 | 빠른 평균에서 느린 평균을 뺀 것 |
| **거래량** Ὄγκος | 아래 칸에 따로 | 막대는 그날, 줄은 평균 |

상대강도와 MACD 를 봉과 같은 자리에 겹치면 둘 다 못 읽는다 — 코스피는
6900 이고 상대강도는 38 이다. 그래서 값의 단위가 다른 것은 아래 칸에
따로 그린다.

셈하는 곳은 [`indicators.js`](assets/js/market/indicators.js) 한 곳뿐이다.
차트도 여기서 가져다 그리고 전략 시험도 여기서 가져다 판단한다. 두 곳에서
따로 셈하면 눈으로 본 것과 시험한 것이 어긋난다.

만든 것은 이 브라우저에 남는다.

## 6-2-2. 수식을 직접 쓴다

틀에 박힌 지표만으로는 하고 싶은 셈이 늘 남는다. 지표 서랍에서
**수식**을 더하면 직접 적을 수 있다.

```
(close - ma(close, 20)) / ma(close, 20) * 100
```

| 쓸 수 있는 값 | |
|---|---|
| `close` `open` `high` `low` `volume` | 그날의 값 |
| `hl2` `hlc3` `ohlc4` | 섞은 값 |
| `range` `body` | 고가−저가, 종가−시가 |

| 쓸 수 있는 함수 | |
|---|---|
| `ma(x,n)` `ema(x,n)` `rsi(x,n)` | 평균과 강도 |
| `diff(x,n)` `pct(x,n)` `prev(x,n)` | 며칠 전과 견주기 |
| `highest(x,n)` `lowest(x,n)` `sum(x,n)` `stdev(x,n)` | 지난 며칠 안에서 |
| `abs` `sqrt` `log` `round` `min` `max` `clamp` | 셈 |

수식은 봉 하나가 아니라 **줄 전체**를 다룬다. `close` 는 종가 하나가
아니라 종가의 줄이고, `ma(close, 20)` 은 그 줄의 이동평균 줄이다.
그래서 한 번 적으면 모든 날에 대해 한꺼번에 셈해진다.

### eval 을 쓰지 않았다

한 줄이면 될 일이다. 그런데 `eval` 은 적힌 것을 그대로 실행한다 —
수식이 아니라 무엇이든. 이 사이트는 설정을 파일로 주고받고 그 파일에는
수식도 담기므로, 남이 준 파일 한 장이 이 페이지에서 아무 코드나 돌릴
수 있게 된다.

그래서 직접 읽는다 ([`formula.js`](assets/js/market/formula.js)).
숫자, 이름, 괄호, 사칙연산, 그리고 위 표의 함수뿐이다. 그 밖의 글자를
만나면 **몇 번째 글자가 잘못됐는지** 알려 주고 멈춘다.

```
fetch("//evil")   →  쓸 수 없는 글자입니다: " (7번째 글자)
close.constructor →  쓸 수 없는 글자입니다: . (6번째 글자)
close +++         →  여기에서 수식이 끊겼습니다 (10번째 글자)
```

틀린 수식이 차트를 죽이지도 않는다. 빈 줄을 돌려주고 왜 틀렸는지만
적어 둔다 — 반쯤 적다 만 수식 때문에 보고 있던 줄이 사라지면 성가시다.

## 6-3. 전략을 시험한다 — `Δοκιμή`

규칙을 짜서 지난 시세에 대어 본다.

```
언제 사나   이동평균 20 이 이동평균 60 을 위로 뚫는다
언제 파나   이동평균 20 이 이동평균 60 을 아래로 뚫는다
지킴이     손절 0% · 익절 0% · 수수료 25bp
```

**먼저 적어 둘 것.** 지난 시세에서 잘 들었다는 것은 앞으로도 그러리라는
뜻이 아니다. 숫자가 좋아질 때까지 규칙을 고치면, 그것은 시장을 배운 것이
아니라 지나간 우연을 외운 것이다. 그래서 성적에는 늘 **“그냥 사서 들고
있었다면”** 이 나란히 붙는다. 그것을 이기지 못하는 전략은 아무것도 아니다.

### 셈하는 규칙

* 신호는 그날 **종가로 판단**하고 **다음 날 시가에 체결**한다.
  같은 날 종가로 사고파는 것은 실제로 할 수 없는 일이다
* **수수료와 미끄러짐을 양쪽에 매긴다.** 이것을 빼면 자주 사고파는 전략이
  실제보다 훨씬 좋아 보인다
* 살 때는 가진 돈을 전부 쓴다. 공매도는 다루지 않는다 — 없으면 쉰다

### 나오는 숫자

총수익 · 연평균 · **최대낙폭**(꼭대기에서 얼마나 내려갔었나) · 사서 보유 ·
**초과**(사서 보유를 얼마나 이겼나) · 매매 횟수와 승률 · 손익비 ·
**시장 체류**(나가 있던 날의 비율). 자산 곡선에는 전략과 사서 보유가
겹쳐 그려지고, 사고판 자리에 점이 찍힌다.

셈은 [`engine.js`](assets/js/backtest/engine.js) 가 한다.

## 6-5. 분석 — `Ἀνάλυσις`

차트는 하나를 깊이 본다. 이 화면은 **여럿을 나란히 놓고 견준다.** 그
둘은 다른 일이다 — 삼성전자 차트를 아무리 오래 봐도 그것이 코스피보다
더 흔들리는지는 알 수 없다.

지켜보는 것 전부의 한 해치를 한 번에 부른다(`spark`, 부름 한 번).
분석에 쓰는 숫자는 전부 종가만 있으면 셈해지기 때문이다.

### 표

| 줄 | 무엇 |
|---|---|
| 1주 · 1달 · 3달 · 6달 · 1년 | 구간 수익률 |
| 흔들림 | 한 해로 늘린 변동성. 지금까지 이 정도로 널뛰었다는 뜻 |
| 최대 낙폭 | 꼭대기부터 가장 깊이 팠던 자리 |
| 지금 낙폭 | 꼭대기에서 지금 얼마나 내려와 있나 |
| 폭 안 자리 | 한 해 폭에서 0은 바닥, 100은 꼭대기 |

머리를 누르면 그 줄로 정렬한다. 숫자 열둘을 나란히 놓으면 사람은 그중 큰
것을 못 찾는다. 정렬을 한 번 누르면 찾는다. **표에서 정렬은 장식이 아니라
본체다.**

> **왜 로그수익률인가.** 흔들린 정도를 잴 때는 `(오늘/어제 − 1)` 대신
> `ln(오늘/어제)` 를 쓴다. 더하면 그대로 구간 수익률이 되기 때문이다.
> 백분율 수익률은 더해도 맞지 않는다 — +50% 뒤 −50% 는 0이 아니라 −25% 다.
>
> **왜 √252 인가.** 하루치 표준편차를 한 해 것으로 늘릴 때 쓴다. 한 해에
> 장이 서는 날이 대략 252일이고, 흔들림은 시간의 제곱근에 비례해 커진다.
>
> **왜 최대 낙폭인가.** 수익률보다 이쪽이 사람에게는 더 중요하다. 다섯
> 해에 두 배가 되는 길이라도 도중에 반토막이 났다면 대개 그 자리에서 손을
> 뗀다. 견딜 수 없는 길은 좋은 길이 아니다.

### 열지도

두 값이 같이 움직이는 정도다. +1 이면 늘 같은 쪽으로, −1 이면 늘 반대쪽
으로, 0이면 상관없이.

**열 가지를 지켜본다면서 열 가지가 다 +0.9 로 붙어 있다면, 사실은 한
가지를 열 번 들고 있는 것이다.** 나눠 담았다고 믿을 때 여기를 먼저 본다.

날짜를 맞춰 짝지어 셈한다. 서울과 뉴욕은 장이 서는 날이 다르므로 그냥
늘어놓고 견주면 하루씩 밀린 채로 셈하게 된다.

### 한 줄로

숫자를 사람의 말로 옮긴 한 줄이다. **판단이 아니라 서술이다.** "사야
한다" 는 말은 여기서 나오지 않는다 — 지나간 값만 보고 앞을 말하는 것은
거짓말이기 때문이다.

## 6-5-2. 하나만 깊이 — 격자 · 분포 · 롤링

분석 화면 아래에서 종목 하나를 골라 세 가지를 더 본다.

**월별 격자** — 세로에 연도, 가로에 열두 달. 계절성이 있으면 세로줄로
보이고 없으면 얼룩으로 보인다. 대개는 얼룩인데, **얼룩이라는 것을 눈으로
보는 것**이 이 판의 값이다.

**수익률 분포** — 히스토그램 위에 같은 평균·표준편차의 정규곡선을 겹친다.
가운데는 더 뾰족하고 양 끝은 더 두껍다는 것이 한눈에 보인다. 실제로 코스피
두 해치에서 초과첨도 7.9, 3시그마 밖이 정규분포라면 1.3일이어야 할 것이
11일이었다. **그 두꺼운 꼬리가 사람을 망하게 하는 자리다.**

**롤링 수익률** — 아무 날에나 들어갔다면 1년·6달·3달 뒤에 어땠나의
최악·중앙·최선. 한 시점의 1년 수익률은 그 시점 이야기지만, 이것은 실제로
나에게 벌어지는 일에 더 가깝다.

## 6-6. 견주어 보기

차트에서 **비교** 를 누르고 하나라도 걸면 눈금이 값에서 **백분율**로
바뀐다. 코스피 3천과 애플 230은 같은 눈금에 못 올리지만, "이 구간에서 몇
퍼센트 움직였나" 는 올릴 수 있다. **견줄 수 있는 것은 값이 아니라 움직인
정도다.**

창 왼쪽 끝이 0% 다. 창을 옮기면 기준도 함께 옮겨 간다 — "지금 보고 있는
이 구간에서" 를 재는 것이므로.

여기서도 날짜를 맞춰 짝짓는다. 개수만 맞춰 붙이면 하루씩 밀린 그림이
나오는데, **밀린 그림은 틀린 그림보다 나쁘다** — 틀린 줄은 알아보지만
하루 밀린 줄은 알아보지 못하기 때문이다. 짝이 없는 날은 선이 끊긴다.

다섯까지만 걸린다. 더 얹으면 결이 안 보인다.

### 비율 — 견줄 것이 딱 하나일 때

**비율** 을 누르면 두 값을 나눈 줄 하나가 된다. 두 곡선을 겹쳐 놓으면 눈이
그 사이를 재야 하는데 **사람은 두 곡선 사이의 간격을 잘 못 잰다.** 나눠
놓으면 잴 필요가 없다 — 올라가면 이쪽이 이기는 중이고 내려가면 지는 중이다.

띠는 그 줄의 평균에서 표준편차만큼 떨어진 자리다. 오른쪽 끝에 지금이 몇
시그마인지 적힌다. 2를 넘으면 드물게 벌어진 것이고, 대개는 되돌아온다. 대개는.

### 값대별 거래량

**값대별** 을 누르면 가격대별 거래량이 왼쪽에서 자란다. 시간축 거래량은
"언제 많았나" 를 말하고 이것은 **"어느 값에서 많았나"** 를 말한다.

한 봉의 양을 종가 한 점에 몰아넣지 않고 그 봉의 고저 사이에 고르게 편다.
하루에 값이 3% 움직였다면 그 3% 구간 어디에서든 거래가 있었을 것이고,
종가에 다 몰면 없는 봉우리가 생긴다.

## 6-7. 비중과 지도 — 시험 화면의 나머지 두 갈래

### 비중 `Μερίς`

종목을 고르는 대신 **비중**을 고른다. 개인에게는 이쪽이 성과를 더 많이
정하는데, 화면은 늘 종목 고르기 쪽에만 있다. 규칙을 스무 번 고치는 것보다
비중을 한 번 정하는 것이 대개 더 큰 차이를 낸다.

| | |
|---|---|
| 되돌리기 | 안 함 · 달마다 · 분기마다 · 반년마다 · 해마다 · 어긋나면 |
| 견주는 것 | 같은 비중으로 사서 **아무것도 안 한 경우** |
| 곁들이 | 적립식과 일시납을 같은 총액·같은 기간으로 |

수수료는 **옮기는 금액에만** 문다. 그대로 두는 몫에는 물지 않는다.

> 눈금은 늘 하루로 고정한다. 주간봉은 거래소마다 주가 시작하는 요일이 다르게
> 찍혀 나와, 서울과 뉴욕을 날짜로 짝지으면 하나도 안 맞는다.

### 지도 `Χάρτης`

**이 사이트에서 가장 정직한 판이다.**

규칙 갈래에서 짠 전략의 숫자 둘을 격자로 돌려 성적을 색으로 칠한다.

* 봉우리가 **넓고 완만하면** 20일이든 22일이든 비슷하게 된다는 뜻
* 봉우리가 **뾰족하면** 21일에만 되고 20일과 22일은 안 된다는 뜻

뒤엣것은 시장의 성질이 아니다. 지나간 값의 우연이다. 뾰족함을 0에서 100
사이의 숫자로 내고, 무엇을 뜻하는지 한 줄로 적어 준다.

그 아래가 **워크포워드**다. 앞 70%에서 가장 좋았던 값을 골라, 그 값 그대로
뒤 30%에서 시험한다. 고르는 자료와 시험하는 자료가 같으면 **시험 문제를
보고 공부한 것**과 같다.

이것을 통과하는 전략은 드물다. **드문 것이 정상이다.** 뒤 구간에서 한 번도
사지 않았으면 그렇다고 말한다 — 그것도 답이다.

> 이 사이트는 시험 화면에 "지나간 우연을 외운 것" 이라고 경고문을 달아 두었다.
> 경고문은 아무도 안 읽고 그림은 본다. 이 판은 그 경고를 그림으로 바꾼다.

### 원화로 보면

차트에서 **원화** 를 누르면 해외 자산이 원으로 환산된다. 그리고 수익을
**값이 낸 몫**과 **환율이 낸 몫**으로 가른다.

실제로 애플 6개월을 재 보면: 달러로 +18.8%, 원화로 +12.2%. 환율이 −6.6%를
먹었다 (1,462 → 1,380). 한국에서 해외 자산을 보는 사람에게 이 분해는 거의
언제나 빠져 있고, **빠진 채로 성과를 오해한다.**

### 재무 — 회사가 제출한 원본

차트에서 **재무** 를 누르면 매출·순이익·주당순이익·자산·자본·**주식수**
열 해치가 뜬다. 색은 전년 대비다.

주식수가 해마다 늘고 있으면 그만큼 내 몫이 옅어지는 중이라는 뜻인데,
**그것이 여기서 가장 자주 놓치는 줄이다.**

미국 상장사만 있다. 한국 종목은 DART 쪽이고 그것은 아직 공시까지만 본다 —
반쪽인 것을 알고 두는 반쪽이다.

### 밑에 깔린 것

수익률곡선(10년−2년, 10년−3달) · 10년 국채 · 실질금리 · 하이일드 가산금리 ·

그런데 **모든 종목 차트를 다르게 읽게 만든다.**

### 공시

관심종목 가운데 한국 종목의 최근 공시를 소식 목록에 섞는다. 유상증자·최대주주
변경·감사의견 거절 같은 것은 **기사보다 공시가 먼저**이고, 기사를 기다리면
이미 값이 움직인 뒤다. 급한 것은 속보로도 뜬다.

> **Stooq 를 쓰려다 그만두었다.** 열쇠 없이 CSV 를 주는 곳이라 시세 뒷길로
> 두려 했는데, 헤더만 보면 200 이 오지만 본문은 자바스크립트로 푸는 문제였다.
> 사람이 아닌 것을 거르려고 세운 문이라 넘지 않기로 했다. 대신 열쇠가 필요하되
> 공짜인 Alpha Vantage 를 뒷길로 두었다.
>
> **헤더만 보고 판단하지 말 것.** 이 자리에서 한 번 속았다.

## 6-9. 일지 성적표 — 이 사이트만 할 수 있는 것

일지에는 이미 **그날의 시세 스냅샷**이 함께 저장된다. 그러면 셈할 수 있는
것이 생긴다 — 그 글을 적은 날 이후 **30일·90일에 그 종목이 어떻게 되었나.**
마음(오름을 본다 / 내림을 본다 / 움직였다 …)별로 갈라서.

```
Ταῦρος  오름을 본다   30일 뒤  +4.4%   6번 중 83% 맞음
Ἄρκτος  내림을 본다   30일 뒤  +0.8%   6번 중 33% 맞음
        → 오를 때를 보는 눈이 내릴 때를 보는 눈보다 낫습니다.
```

이름표(#태그)별로도 낸다. "#불안" 을 달았던 날들의 이후 30일이 평균 몇 %였는지.

**어떤 상용 사이트도 이것을 못 한다 — 내 일지가 없기 때문이다.**

사이트가 "사람의 기억은 결과에 맞추어 고쳐집니다" 라고 써 놓고 일지를 권했다.
그러면 다음 걸음은 정해져 있다 — **고쳐지지 않은 기록으로 나를 채점하는 것.**
적어 두게 하는 데서 멈추면 일지는 그냥 일기다.

지키는 것:

* 다섯 개 아래로는 숫자를 내지 않고 "아직 모자랍니다" 라고 말한다
* 30일이 아직 안 지난 글은 세지 않는다 — 세면 최근 글이 늘 0%로 끌어내린다
* **이것은 예측력의 증명이 아니다.** 지나간 한 구간의 기록일 뿐이다.
  그래도 기억보다는 정확하다

## 6-10. 장부 — `Κτῆσις`

이 사이트가 오래 못 하던 것은 기능 하나가 아니라 한 가지 사실이었다.
내가 실제로 무엇을 들고 있는지 몰랐다. 모든 숫자가 **"고르게 담았다면"**
이라는 가정 위에 있었다.

거래를 적으면 나머지가 전부 진짜가 된다 — 위험 기여도는 내 비중으로,
스트레스 재생은 내 조합으로, 세금은 내 실현손익으로.

| 갈래 | 무엇 |
|---|---|
| **보유** | 무엇을 얼마나 · 평균단가 · 평가손익 · 거래 적기 |
| **성과** | TWR 과 MWR |
| **세금** | 올해 낼 세금 · 손실 수확 · 종합과세 문턱 |

잔고가 아니라 **거래**를 적는다. 잔고만 알면 "언제 넣었나" 를 알 수 없고,
그것을 모르면 내가 실제로 번 것을 셈할 수 없다.

평균단가는 이동평균법이다. 그리고 **팔 때 평균단가는 안 움직인다** —
백 주를 만 원에 사고 오십 주를 이만 원에 팔면 남은 오십 주의 단가는
여전히 만 원이고, 남긴 이익은 실현손익으로 따로 빠진다. 흔한 실수다.

> 장부는 이 브라우저에만 남고 `settings.json` 에는 **담기지 않는다.**
> 그 파일은 웹호스팅에 올려도 된다고 적어 두었는데, 매매 내역이 거기
> 있으면 안 된다. 옮기려면 장부 화면의 내보내기를 쓴다.

### TWR 과 MWR — 이 사이트에서 가장 불편한 숫자

**TWR**(시간가중)은 돈을 언제 넣었는지를 지운 수익률이다. 펀드 광고에
뜨는 것이 이것이다. **MWR**(금액가중, XIRR)은 내가 실제로 번 것이다.

```
TWR 연 +58.3%    상품이 번 것
MWR 연 +60.7%    내가 번 것
그 차이  +2.4%   ← 언제 넣고 뺐는지가 낸 몫
```

**그 간격이 곧 내 타이밍의 값이다.** 꼭대기에서 더 넣고 바닥에서 못
넣었으면 MWR 이 낮다. 어느 앱도 이 둘을 나란히 안 보여 준다 — 보여
주면 대개 부끄러운 숫자가 나오기 때문이다.

셈하는 법: 장부와 시세를 겹쳐 날마다의 평가액을 만들고, 흐름이 있는
날은 **그 흐름을 빼고** 나눈다. 그러지 않으면 돈을 넣은 날마다 수익이
난 것으로 셈해진다.

> 한 달이 안 된 장부는 연율로 펴지 않는다. 사흘에 2% 번 것을 연율로
> 펴면 900% 가 되는데, 셈은 맞지만 그 숫자는 거짓말이다.

### 세금과 손실 수확

이 사이트의 다른 숫자는 전부 "지난 값이 이랬다" 는 이야기다. **이것만은
계산이고, 계산은 맞거나 틀리거나 둘 중 하나다.** 수익률을 맞히는 것보다
세금을 덜 내는 것이 훨씬 확실하다.

손실 수확은 "지금 손실 중인 해외 종목을 얼마만큼 팔면 올해 양도세가
얼마나 주는가" 를 낸다. **필요한 만큼만 권한다** — 올해 차익이 기본공제
아래로 내려가면 그 뒤로는 더 팔아도 세금이 안 줄기 때문이다.

> 이것은 **세금을 없애는 것이 아니라 미루는 것**이다. 다시 사면 취득가가
> 낮아져 나중에 그만큼 더 낸다. 그래도 미루는 것만으로 값이 있다 —
> 그 돈이 그동안 일한다.
>
> 세율은 화면에서 고칠 수 있다. 코드에 박아 두면 세법이 바뀐 다음 해에
> 틀린 숫자를 자신 있게 내놓는다. **이것은 세무 상담이 아니다.**

## 6-11. 나쁠 때만 드러나는 것 둘

### 무너지는 상관

열지도는 **평균** 상관을 보여 준다. 그런데 상관은 폭락할 때 1로
수렴한다 — 분산이 필요한 바로 그 순간에.

기준 지수가 2% 넘게 내린 날만 골라 다시 재면 이런 것이 나온다.

```
금 · 비트코인    평소 0.06    내리는 날 0.40
S&P 500 · 금     평소 0.08    내리는 날 0.31
```

> 고르는 잣대가 재려는 것과 같아지면 안 된다. 두 종목이 **함께** 내린
> 날만 고르면 당연히 상관이 1에 가깝게 나온다. 그래서 제3의 것(시장)이
> 내린 날로 고르고, 그 안에서 둘의 관계를 잰다.

### 스트레스 재생

**예측이 아니라 재생이다.** "그때가 다시 오면" 이 아니라 "그때를 지금
조합으로 겪었다면".

2008 금융위기 · 2011 유럽 · 2018 4분기 · 2020 코로나 · 2022 긴축.
실제로 있었던 구간의 날마다 움직임을 지금 비중에 그대로 댄다.

```
코로나 급락 (33일)   내 조합 −22.7%   코스피 −32.9%
  애플 51%  −29.2%     삼성전자 19%  −29.4%     금 30%  −7.7%
```

그때 없던 것은 지수에 대한 베타로 갈음하고 **반드시 표를 단다.**
지어낸 값을 진짜처럼 보이게 하는 것이 이 판에서 가장 나쁜 일이다.
갈음한 비중이 절반을 넘으면 "재생이라기보다 짐작" 이라고 적는다.

이 판만은 스무 해치를 따로 받는다 — 분석이 쓰는 두 해치로는 2008년에
값이 하나도 없다. 열두 종목 스무 해 일봉이 묶음 부름 한 번에 0.5초쯤이다.

## 6-12. 배당

오래 든 사람에게는 이 숫자가 본 숫자다. 값이 오르내리는 것은 내가 못
정하지만, 배당은 회사가 해마다 정해서 실제로 보내 준다.

**취득가 대비 배당률(yield on cost)** 이 요점이다. 삼만 원에 사서 지금
십만 원인 것이 주당 삼천 원을 준다면 새로 사는 사람에게는 3%지만
나에게는 10%다. 같은 배당인데 다른 숫자이고, 나에게 맞는 쪽은 뒤엣것이다.

배당을 다시 사들였다면 얼마나 달랐는지도 낸다 — 긴 시간에서는 이 차이가
수익의 절반쯤을 내는데, **대부분의 차트는 배당을 아예 안 그린다.**

> **분할을 지나칠 수 없다.** 4대1 분할이 있었으면 그 전의 주당 배당금은
> 4로 나눠야 지금 주식과 견줄 수 있다.
>
> **반쪽인 해를 성장률에서 뺀다.** 열 해치를 받으면 첫 해는 대개 반쪽인데,
> 그것을 시작점으로 삼으면 애플 배당 성장이 연 45% 라는 거짓말이 나온다.
> 한 해에 몇 번 주는 것이 보통인지를 세어 그보다 적게 받은 해를 잘라 낸다
> (그러면 26.8% 로 바로잡힌다).

## 6-13. 규칙 감시

일지 성적표가 "판단이 맞았나" 를 채점한다면, 이것은 **"내가 적어 둔 대로
했나"** 를 채점한다. 대부분의 손실은 규칙이 틀려서가 아니라 안 지켜서 난다.

```
삼성전자 — 꼭대기에서 −20% 아래로 내려가면 들여다본다
  3월 4일에 걸렸습니다 (172,200). 그 뒤로 +50.1%.
```

걸린 날을 찾아 "그대로 했다면 지금보다 몇 % 나았나" 를 낸다. **어겨서
이득을 본 경우도 그대로 보여 준다** — 그것도 사실이고, 숨기면 이 판은
잔소리가 된다.

> **글에서 뽑아내지 않는다.** "−10%면 판다" 를 한국어 문장에서 알아채게
> 만들 수도 있었지만, 그런 것은 늘 반쯤만 맞는다. 반쯤 맞는 것을 근거로
> "당신은 규칙을 어겼습니다" 라고 말하면 틀렸을 때 그 말이 아주 나쁘다.
> 그래서 규칙은 손으로 또렷하게 걸고, 왜 세웠는지만 글에 남긴다.

## 6-14. 누가 사고 있나 — 투자주체

국내 시장에만 있는 숫자다. 개인·기관·외국인이 각각 하루에 얼마나
사고팔았나를 거래소가 내준다. 미국에는 이런 것이 없다 (13F 는 분기에
한 번, 45일 늦게 온다).

받아 오는 곳은 네이버 모바일이다 —
`m.stock.naver.com/api/stock/{종목}/trend`. 지수는 `index` 쪽으로 간다.

| 판 | 무엇을 답하나 |
|---|---|
| 같은 날 | 그날 산 주체와 그날 등락이 얼마나 같이 가나 |
| **앞선 날** | 오늘 산 것이 **1·5·20일 뒤** 값과 상관이 있나 |
| 평균 단가 | 이 구간에서 새로 사 모은 몫의 평균값 |
| 함께 산 날 | 셋이 **동시에** 산 드문 날, 그 뒤에 무슨 일이 |
| 보유율 선행성 | 지분이 먼저 움직이고 값이 따라가나 |

같은 날 상관은 거의 언제나 나온다 — 값이 오르면 개인이 팔고 외국인이
산 것으로 기록되기 때문이다(−0.80 쯤). 그것은 발견이 아니라 정의에
가깝다. 볼 만한 것은 **앞선 날** 쪽이고, 거기서 표본이 20일이 안 되면
아예 숫자를 내지 않는다.

> **평단은 진짜 평단이 아니다.** 외국인은 삼성전자를 수십 년 들고 있고
> 그 취득가는 아무도 모른다. 여기 나오는 것은 *이 구간에서 새로 사 모은
> 몫*의 평균이다. "외국인 평단 7만" 이라고 말하면 거짓말이 된다 —
> 그래서 판 아래에 그대로 적어 두었다.

## 6-15. 하루 안 — 분봉

일봉은 하루를 네 숫자로 줄인다(시·고·저·종). 그 넷으로는 답할 수 없는
물음이 있다.

기간에서 `1일` 을 고르면 1분봉, `5일` 이면 5분봉으로 바뀐다. 야후는
분봉을 최근 것만 준다 — 1분은 7일치, 그보다 굵은 것은 60일치까지다.
`symbols.js` 의 `INTRADAY` 가 기간마다 고를 수 있는 간격을 쥐고 있다.

### VWAP — 거래량으로 무게를 준 평균값

기관은 하루 종일 나눠 산다. 그래서 그들의 체결가는 종가가 아니라 여기에
가깝다. **"지금 값이 VWAP 위인가 아래인가"** 는 *"오늘 산 사람들
평균보다 비싼가 싼가"* 를 묻는 것이다.

```
삼성전자   지금 256,500 · VWAP 260,420 · 그 차이 −1.51%
           → 오늘 산 사람 대부분이 물려 있다
```

대표값은 `(고+저+종)/3` 을 쓴다. 종가만 쓰면 그 봉 안에서 오간 값을
무시하게 된다. 그리고 **날이 바뀌면 0에서 다시 쌓는다** — 어제 것을
이어 셈하면 어제 산 사람의 값이 오늘 판단에 섞인다.

### 갭 · 시간대 · 체결 강도

| | |
|---|---|
| 갭 | 어제 종가와 오늘 시가 사이의 틈. **위로 열린 갭 127번 중 41% 가 그날 안에 메워졌다** |
| 시간대 | 30분마다 움직임의 크기를 더한다. 삼성전자는 **09:00 에 하루 움직임의 17%**, 12:30 이 가장 잠잠하다 |
| 체결 강도 | 봉 안에서 값이 위쪽에 붙어 끝났나 아래쪽에 붙어 끝났나. 거래량을 곱해 쌓으면 값은 제자리인데 이 줄이 오르는 자리가 보인다 |

갭은 **방향을 갈라** 본다. 위로 뛴 갭과 아래로 빠진 갭은 다르게
행동하는데, 합쳐 놓으면 둘이 서로를 지운다.

## 6-16. 실시간 — 여기만 다리를 놓지 않는다

이 사이트의 다른 모든 것은 프록시를 거쳐 온다(§2). 실시간만은
곧바로 간다 — **WebSocket 은 CORS 를 묻지 않기 때문이다.** 정적
페이지에서 진짜 실시간이 되는 것은 이 한 가지 사실 덕분이다.

```
wss://streamer.finance.yahoo.com/?version=2
  → { subscribe: ['005930.KS', '^KS11', 'BTC-USD', ...] }
  ← base64(protobuf)  한 줄에 한 종목
```

야후는 protobuf 로 싸서 base64 로 보낸다. 라이브러리를 넣을 수 없어
([빌드 도구가 없다](#7-구조)) **해독기를 손으로 썼다** —
[`net/live.js`](assets/js/net/live.js). 필요한 것은 네 가지 형(0·1·2·5)
뿐이고, 시각은 지그재그로 감겨 온다.

| | |
|---|---|
| 그리는 주기 | 1초에 한 번. 오는 대로 그리면 창이 탄다 |
| 끊겼을 때 | 1 → 3 → 8 → 20 → 60초로 물러서며 다시 건다 |
| 막혔을 때 | **아무 일도 일어나지 않는다.** 몇 분 늦은 값으로 그대로 돈다 |

차트 위 **초록 점**이 켜져 있으면 흐르는 중이다. 회사 방화벽은
WebSocket 을 자주 막는다 — 나머지 시세는 다 들어오는데 이것만 막히는
일이 흔해서, [진단](#7-2-무언가-안-보일-때--진단html) 에 따로 칸을 두었다.

## 6-18. 흐르는 화면 셋

### 열지도

지켜보는 것 전부를 한 판에 칠한다. 칸 크기는 **모두 같게** 둔다.
시가총액으로 크기를 나누는 방식이 흔하지만, 이 목록에는 지수와
원자재와 환율이 섞여 있어 그 방식은 뜻이 없다.

### 오늘 이상한 것

등락률로 줄 세우지 않는다. **제 평소 흔들림으로 나눠** 세운다.

```
원·달러 환율   −0.82%   −1.4σ
```

그냥 줄 세우면 늘 비트코인이 맨 위에 오고, 그것은 소식이 아니다.
0.82% 움직인 환율이 5% 움직인 코인보다 훨씬 이상한 일이다.

### 브라우저 알림

**탭이 열려 있을 때만 울린다.** 서버가 없으니 푸시는 못 한다 — 그
한계를 숨기지 않고 화면에 그대로 적었다. 숨기면 "왜 안 울렸지" 를
묻게 되고, 그때 사이트 전체를 덜 믿게 된다.

창을 보고 있으면 띄우지 않는다(`document.hidden` 일 때만). 이미
화면에서 봤을 것이므로.

## 6-19. 자료 — 남이 만든 표를 들인다 (`Πίναξ`)

이 사이트의 다른 모든 숫자는 야후나 거래소에서 온다(§2). 그런데 정작
자기 돈은 대개 다른 곳에 적혀 있다 — 퇴직연금 명세서, 펀드 기준가 이력,
증권사가 내려 준 거래내역, 손으로 적어 둔 엑셀.

**올린 파일은 이 브라우저를 떠나지 않는다.** 서버가 없으니 보낼 곳도
없다. 그 말을 들이는 자리에 적어 두었다 — 명세서를 올리라고 하면서 그
말이 없으면 아무도 올리지 않는다.

| | |
|---|---|
| 읽는 것 | `.xlsx` · `.csv` · `.tsv` · `.json` |
| 못 읽는 것 | `.xls` (옛 이진 형식). 그렇다고 말하고 xlsx·CSV 로 바꾸는 길을 알려 준다 |

### 엑셀을 라이브러리 없이 읽는다

xlsx 는 사실 **zip** 이고 안에 든 것은 **XML** 이다. 브라우저에 압축을
푸는 기계가 이미 들어 있다(`DecompressionStream`). zip 의 목차를 손으로
읽고 꺼낸 XML 을 `DOMParser` 로 편다. 1,455줄짜리가 **91ms**.

> **엑셀은 날짜를 숫자로 적는다.** 2026-08-28 이 파일 안에서는 46262 다.
> 그 숫자가 날짜인지는 서식(`styles.xml`)을 봐야만 안다. 이걸 안 보면
> 명세서의 날짜 열이 통째로 다섯 자리 숫자가 되고, 그러면 시계열 분석을
> 아예 걸 수 없다.

### 국내 CSV 의 버릇

증권사가 내려 주는 것은 아직도 **EUC-KR** 이 많다. UTF-8 로 읽어 보고
깨진 글자가 눈에 띄면 EUC-KR 로 다시 읽어 견준다. 덜 깨진 쪽을 쓴다.

```
"1,200"        → 1200        천 단위 쉼표
"82,200,000원" → 82200000    원화 표시
"(1,340,000)"  → -1340000    회계식 괄호 음수
```

> **여기서 한 번 크게 틀렸다.** 날짜 구분자를 각각 있어도 되고 없어도
> 되게 두었더니 기준가 `1002.53` 이 *1002년 5월 3일*로 읽혔다 —
> `1002 · . · 5 · (없음) · 3` 으로 갈린 것이다. 그 열이 통째로 날짜가
> 되어 그래프에서 사라졌다. 날짜는 구분자를 섞어 쓰지 않으므로 둘이
> 같아야 하고(``), 해도 1900~2200 으로 가뒀다.

### 네 칸

| | |
|---|---|
| 표 | 읽은 것을 그대로. **무엇으로 읽혔는지**(날짜·숫자·글)를 함께 적는다 — 여기가 틀리면 아래가 전부 틀린다 |
| 그림 | 선 · 막대 · 점 (회귀선을 얹는다) |
| 셈 | 요약 · 분포 · 상관 · 회귀 · 정규성 |
| 시계열 | 날짜 열이 있으면 시세와 똑같이 — 연평균 · 흔들림 · 낙폭 · 물 아래 |

**p 값을 근사로 대충 내지 않았다.** t 분포를 불완전 베타로 제대로 센다.
개인이 올리는 표는 대개 작고(열두 달, 스무 종목), 작을 때 틀리는 셈은
여기서 쓸모가 없다. 알려진 답 열여섯 가지로 맞춰 보았다 — `t=2.228`,
`df=10` 이 `p=0.0500` 으로 나온다.

> **다중회귀는 넣지 않았다.** 설명변수를 늘리면 거의 언제나 R² 가
> 오르는데, 그것을 '더 잘 설명한다' 로 읽기 쉽고 대개는 그냥 자유도를
> 쓴 것이다. 그 함정을 화면에서 막을 자신이 없으면 넣지 않는 편이 낫다.

흔들림과 샤프는 `analysis.js` 것을 쓰지 않고 여기서 직접 센다. 그쪽은
시세를 다루므로 하루·주·달만 아는데, 올라오는 표는 분기나 해 단위가
흔하고 그때 252를 쓰면 흔들림이 열 배 넘게 부푼다.

## 6-20. 격언 — 남들이 한 말 (`Γνῶμαι`)

'투자 격언'을 파는 곳은 많다. 대개 출처도 날짜도 없이 떠도는 글귀
모음이고, **버핏이 했다는 말의 절반쯤은 버핏이 한 말이 아니다.**

그래서 글귀 모음을 사 오지 않는다. 실제로 보도된 글에서 **따옴표 안에
든 말만** 꺼내고, 누가·어디서·언제를 반드시 함께 적는다. 출처를 못 대는
말은 싣지 않는다.

### 기사 제목은 기자가 쓴 말이다

「버핏, 시장 과열 경고」는 버핏이 한 말이 아니라 기자가 요약한 말이다.
그것을 격언으로 실으면 그 사람이 하지 않은 말을 그 사람 이름으로 싣는
것이 된다. 따옴표가 없으면 그 기사는 버린다.

버려지는 것이 훨씬 많다. 백 건에서 따옴표는 열 개쯤 나오고 그중 말이라
할 만한 것은 둘이었다.

```
✓ Wealth is not the same as money
✓ The village idiot could have made it
✗ Does Anybody Want That Job?          제목을 따옴표로 감싼 것
✗ Blessing in Disguise,                조각
✗ in three years, give or take two.    문장 가운데를 자른 것
```

### 그 사람이 한 말이 맞나

한 기사 안에 여러 사람의 말이 섞이는 일은 흔하다.

```
Elon Musk Says He's Not Warren Buffett's 'Biggest Fan' …
```

버핏의 이름이 있지만 말한 이는 머스크다. **'이름 + 말했다' 짝이 우리
사람이 아닌 채로 있으면 확인하지 않은 것으로 두고, 화면에 그렇다고
적는다.** 숨기지 않는다.

> 처음에는 '이름 + 말했다'를 함께 요구했더니 여섯 건이 **모두** '확인
> 못 함'이 되었다. 신문 제목은 '말했다'를 잘 안 쓰고 콜론과 소유격이
> 그 자리를 대신하기 때문이다. 모든 칸에 경고가 붙으면 경고가 뜻을 잃는다.

### 지킨 것

* **하루 열 건**에서 멈춘다. 더 담을 수 있지만 스무 개를 읽으면 하나도
  남지 않는다
* 같은 날에는 **같은 열 건**. 새로 고칠 때마다 바뀌면 어제 본 말을 다시
  찾을 수 없다
* 한 사람이 열 자리를 다 먹지 않게 한다 (둘까지, 모자랄 때만 셋)
* 두 달이 지난 말은 뒤로 민다 — '오늘의 열'에 반년 전 것이 섞이면 오늘
  나온 말처럼 읽힌다
* **모든 말에 원문 링크.** 한 문장은 언제나 맥락을 잃는다
* 연설문 **제목**은 격언이 아니다. 따로 「오늘 나온 원문」으로 갈라 둔다

> **방송에서 종목을 찍어 주는 이들은 넣지 않았다.** 그것은 격언이 아니라
> 광고이고, 섞으면 나머지도 같은 것으로 읽힌다.

### 남의 프록시를 아끼는 일

처음에는 스물몇 사람을 각각 물었다. 그랬더니 공개 프록시가 스물몇 번을
한꺼번에 두들겨 맞고 문을 닫았고, 오늘 몫이 통째로 **0건**이 되었다.

다섯 이름을 `OR` 로 묶어 한 번 물으면 백 건이 온다. 요청이 스물여섯에서
열로 줄었다. 남의 호의로 도는 프록시다 — 우리가 조심하지 않으면 다음
사람이 못 쓴다.

## 6-21. 세계 — 시장별 열지도 (`Κόσμος`)

칸 넓이는 **시가총액**, 칸 색은 **오늘 등락**, 묶음은 **업종**이다.
미국·한국·일본·유럽·중국 다섯 시장.

### 왜 여기서는 칸 크기를 다르게 두나

시세 화면의 열지도(§6-18)는 칸을 모두 같게 둔다. 거기에는 지수와
원자재와 환율이 섞여 있어 '크기'라는 것이 아예 없기 때문이다.

여기는 전부 한 시장의 주식이고, 애플이 1% 내리는 것과 작은 회사가 1%
내리는 것은 지수에 미치는 무게가 백 배 넘게 다르다. 그 무게를 칸 넓이로
보여 주지 않으면 "오늘 시장이 왜 내렸나"를 이 그림에서 읽을 수 없다.

칸 나누기는 **squarified treemap** 이다. 값 순서대로 세로로만 자르면
큰 것은 뚱뚱한 기둥, 작은 것은 실오라기가 된다. 실오라기가 된 칸에는
이름을 적을 수 없고, 이름을 못 적으면 그 칸은 없는 것과 같다.
넓이가 값에 정확히 비례하는 것과 칸이 겹치지 않는 것을 맞춰 보았다.

### 상위 종목만 담는다

S&P 500 을 다 담으려면 오백 종목의 시세를 받아야 하고, 그것은 남의
프록시로 할 일이 아니다. 시장마다 위쪽 몇십 개만 담고, **담았다는 사실을
화면에 적는다** — 여기 보이는 것이 지수 전체는 아니다.

> **쉰 개를 한 줄에 물었더니 야후가 문을 닫았다.** 429(너무 잦다)가
> 돌아오고, 그러면 못 받은 쉰 개를 하나씩 다시 묻게 되어 문이 더 굳게
> 닫힌다. 실제로 열지도가 통째로 비었다. 지금은 열둘씩 나눠 순서대로
> 묻고, 못 받은 것은 못 받은 채로 둔다 — 칸 하나가 회색인 것이 판
> 전체가 비는 것보다 낫다.

### 실시간

WebSocket 은 CORS 를 묻지 않는다(§6-16). 열지도에 걸린 종목을 그대로
신청해 두면 값이 오는 대로 칸 색이 바뀌고, 방금 바뀐 칸은 한 번
번쩍인다. 장이 닫혀 있으면 마지막 종가로 칠해진 채 멈춘다.

색은 세 갈래로 자르지 않는다. 빨강/회색/파랑 셋으로만 칠하면 +0.1% 와
+4% 가 같은 색이 된다. 짙기를 이어지게 두되 ±3% 에서 가장 짙어지게
하고, 제곱근으로 늘려 작은 움직임도 눈에 걸리게 한다.

## 6-22. 발산 — 조건에 맞는 것을 찾는다 (`Ἀπόκρισις`)

위에서 하나를 깊이 보고, 아래에서 조건에 맞는 것을 찾는다.

```
찾기      기호나 이름으로 (Enter)
차트      지표 아홉을 켜고 끈다 (이동평균 · 볼린저 · RSI · MACD · …)
상태      이평선 벌어짐 · 줄 선 차례 · 교차 · 체결 강도 · 이격도 · 한 해 자리
투자주체  개인 · 기관 · 외국인 닷새 합
조건      열일곱 개를 켜고 끄고, 숫자를 손으로 고친다
걸린 것   조건에 맞는 종목
```

### 왜 시험 화면과 따로 두나

시험(§6-3)의 규칙은 "언제 사고 언제 파나"를 묻는다. 지난 시세에 대고
돌려 보는 것이라 시간이 흐른다. 여기는 "**지금** 이 조건에 맞는 종목이
무엇인가"를 묻는다. 시간이 흐르지 않고 오늘 하루의 상태만 본다.

백테스트 엔진을 억지로 돌리면 종목 하나마다 오백 일을 걸어가게 되고,
서른 종목이면 만오천 번이다. 마지막 값만 보면 서른 번이다.

### 교차는 '났다/안 났다'로 두지 않는다

"오늘 골든크로스"와 "3주 전 골든크로스"는 전혀 다른 소식인데, 났다/안
났다로만 두면 같아진다. 며칠 전이었는지까지 세고, 사흘 안이면 알람을
띄운다.

이평선 수렴은 5·20·60 이 서로 몇 % 안에 들어와 있는지로 잰다. 다만
**모였다는 것은 방향을 말해 주지 않는다** — 위로 터질지 아래로 터질지
이 숫자는 모른다. 그 말을 화면에 함께 적는다.

### 조건마다 '믿는 것'과 '깨지는 곳'

조건을 켜 놓고 몇 주가 지나면 왜 켰는지 잊는다. 잊은 채로 걸린 종목을
보면 그것이 신호로 보인다. 그래서 조건마다 두 줄을 함께 적었다.

| | 믿는 것 | 깨지는 곳 |
|---|---|---|
| 골든크로스 | 짧은 흐름이 긴 흐름을 넘으면 한동안 같은 쪽으로 간다 | 옆으로 기는 장에서는 넘고 되넘기를 되풀이해, 걸릴 때마다 사면 수수료만 나간다 |
| 정배열 | 오르는 것이 계속 오른다 | 이미 많이 오른 뒤에 걸린다 — 정배열은 결과이지 예고가 아니다 |
| 상대강도 낮음 | 너무 많이 내린 것은 되돌아온다 | 정말로 나빠지는 중일 때도 낮다 |
| 외국인 매수 | 외국인이 꾸준히 사면 값이 따라간다 | 지수 편입이나 환헤지로 사는 일도 많다 |

**모두 맞을 때 / 하나라도 맞을 때**를 고를 수 있다. 조건 여섯을 모두
걸면 대개 아무것도 안 걸리고, 그러면 사람은 조건을 하나씩 끄다가 결국
하나만 남긴다. '하나라도'를 두면 넓게 훑고서 좁혀 갈 수 있다.

> 걸렸다는 것은 "지금 이 조건에 맞는다"는 뜻이지 "오른다"는 뜻이
> 아닙니다.

## 7-2. 무언가 안 보일 때 — `진단.html`

사이트를 띄운 상태에서 `http://localhost:4488/진단.html` 을 연다.
모듈을 하나도 불러오지 않고 혼자 도는 페이지라, 본 사이트가 고장 나
있어도 뜬다. 일곱 가지를 검사한다.

| | 무엇을 보나 |
|---|---|
| 환경 | 브라우저, 창 크기, `file://` 로 연 것은 아닌지, 동작 줄이기 설정 |
| **바깥 연결** | 시세와 소식이 받아지는지, **어느 길로** 받아지는지 (본 사이트와 같은 차례로 두드려 본다) |
| 실시간 | WebSocket 이 열리는지, 실제로 값이 흐르는지 (밤낮없이 뛰는 종목으로 물어 '막힘' 과 '조용함' 을 가른다) |
| 표 읽기 | 엑셀을 브라우저 안에서 풀 수 있는지 — 있다고 말만 하지 않고 **실제로 눌렀다 풀어** 같은 글자가 나오는지까지 본다 |
| 영상 파일 | 스물다섯 편이 다 있는지, 서버가 형식을 바르게 알려 주는지 |
| 영상 재생 | 읽히는지, **실제로 그림이 그려지는지**(픽셀을 떠서 확인), 자동 재생이 되는지 |
| 바깥 열쇠 | FRED·DART·Alpha Vantage 열쇠가 넣어져 있는지, 넣은 것이 실제로 통하는지 |

이 사이트가 고장 나는 자리는 거의 언제나 **바깥 연결**이다. 화면은 뜨는데
숫자가 비어 있다면 거기부터 본다.

맨 아래 상자의 내용을 복사해 보내면 무엇이 문제인지 바로 드러난다.

## 8. 자판

| 키 | |
|---|---|
| `Enter` | 관문을 지난다 |

## 9. 알아 둘 것

* **설정은 이 브라우저에만 남는다.** 서버가 없으니 계정도 없다.
  사생활 보호 창에서는 저장되지 않는다
* **기사 전문은 담지 않는다.** RSS 가 준 제목과 요약까지만 보인다.
  전문은 원문 링크로 간다
* **이 사이트의 어떤 숫자도 사거나 팔라는 말이 아니다.** 전부 지나간
  값에서 곧바로 나온 것이고, 앞을 셈해 주는 숫자는 여기에 없다
* **공개 프록시는 남의 호의로 돈다.** 느리거나 멎을 수 있다.
  오래 쓸 거라면 `api/proxy.php` 가 되는 호스팅을 권한다
* **시세는 지연될 수 있다.** 야후가 주는 대로 보여 준다. 실시간이
  흐르는 동안에는 차트 위 초록 점이 켜지고, 막히면 조용히 늦은 값으로
  돌아간다
* **알림은 탭이 열려 있을 때만 울린다.** 서버가 없어 푸시는 못 한다
* **올린 표는 어디로도 안 간다.** 브라우저 안에서만 열린다
* **격언은 남의 판단이지 권유가 아니다.** 유명한 사람이 한 말이라는 것은
  그 말이 맞다는 뜻이 아니다 — 가장 크게 틀린 예측도 대개 가장 유명한
  사람이 했다
* **세금 숫자는 신고서가 아니다.** 어림이고, 내기 전에 반드시 확인해야
  한다
