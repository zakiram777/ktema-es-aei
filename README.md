# Κτῆμα ἐς Ἀεί

주식·경제·투자 소식을 모으고, 자키람이 읽어 준다.

> *κτῆμα ἐς αἰεὶ μᾶλλον ἢ ἀγώνισμα ἐς τὸ παραχρῆμα ἀκούειν*
> — 투키디데스 『펠로폰네소스 전쟁사』 I.22

빌드 도구가 필요 없는 순수 정적 사이트다. 파일을 그대로 올리면 돌아간다.

---

## 1. 올리기

이 폴더의 내용을 **통째로** 웹 공간의 최상위(`public_html`, `www`, `htdocs` 등)에 올린다.

```
index.html
.htaccess
api/proxy.php
assets/
```

아래는 미리보기·문서용이라 올리지 않아도 된다. 올려도 아무 일도 하지 않는다.

```
SETUP.bat  START.bat  start.sh  serve.mjs  setup.mjs
NODE-REQUIRED.txt  시작하기.txt  README.md  nginx.conf.example
```

`http://내도메인/` 으로 들어가면 관문이 뜬다. **오늘 날짜의 월일 넉 자**를
넣으면 열린다 — 8월 27일이면 `0827`, 12월 12일이면 `1212`.

> 이것은 자물쇠가 아니다. 답이 달력에 적혀 있으니 들어오려는 자를 막지
> 못한다. 막을 셈이었다면 서버가 있어야 하고, 이 사이트에는 서버가 없다.
> 이것은 문턱이다 — 오늘을 알고 온 이에게 열리는. 그리고 브라우저가 소리를
> 내려면 사람의 첫 누름이 필요한데, 그 누름을 받는 자리이기도 하다.
> 날짜는 보는 사람의 기기 시각으로 센다.

> **ES 모듈을 쓰므로 웹서버가 있어야 한다.** `index.html` 을 두 번 눌러
> `file://` 로 여는 방식으로는 뜨지 않는다. 내 컴퓨터에서 먼저 보려면
> 아래 2장을 보라.

## 1-2. 다른 PC 에서 이어서 하기

이 폴더는 **어느 컴퓨터에 갖다 놓아도 그대로 돈다.** 설치할 꾸러미도,
빌드도, 이 컴퓨터에만 있는 경로도 없다. 폴더만 옮기면 끝이다.

### 처음 한 번 — `SETUP.bat`

두 번 누르면 알아서 다 한다.

1. **Node.js 가 없으면 설치할지 묻고 자동으로 깐다** (`winget` 이용).
   winget 이 없으면 [nodejs.org](https://nodejs.org) 를 열어 준다
2. 파일이 온전한지 검사한다 (영상 열세 편까지)
3. `settings.json` 이 있으면 찾아내 알려 준다
4. 바탕화면 바로가기를 만들지 묻는다
5. 사이트를 띄우고 브라우저를 연다

맥·리눅스는 `./start.sh`.

### 그 다음부터 — `START.bat`

| | |
|---|---|
| **윈도우** | `START.bat` 또는 바탕화면 바로가기 |
| **맥 · 리눅스** | `./start.sh` |
| **직접** | `node serve.mjs --open` |

4488 번 문이 이미 쓰이고 있으면 알아서 옆 번호로 옮긴다.

> 배치파일 안에는 한글을 한 자도 넣지 않았다. PC 마다 콘솔 코드페이지가
> 달라 깨지기 때문이다. 사람에게 하는 말은 전부 `setup.mjs`(Node)가 한다.

### 휴대폰이나 옆자리 PC 에서 보기

같은 공유기에 물려 있다면 이 PC 를 켜 둔 채로 볼 수 있다.

```bash
node serve.mjs --lan
```

띄우면 `http://192.168.x.x:4488` 같은 주소를 알려 준다. 그 주소를 다른
기기에 치면 된다. 창을 닫으면 꺼진다.

> 기본값은 이 컴퓨터 안에서만 열린다. `--lan` 을 줄 때만 바깥으로 연다.

### 이 PC 없이 쓰려면

위의 방법들은 모두 **이 PC 가 켜져 있어야** 한다. 아예 떼어 놓으려면
둘 중 하나다.

**ㄱ. 웹호스팅에 올린다 (보기 전용)**
1장대로 올리면 인터넷 주소가 생긴다. 그 뒤로는 아무 기기에서나
주소만 치면 되고, 이 PC 는 꺼져 있어도 된다.

**ㄴ. 폴더를 들고 다닌다 (고치기까지)**
`ktema` 폴더째 아래 어디든 두면, 다른 PC 에서 받아 그대로 이어서 고칠 수
있다.

* **OneDrive · Google Drive · Dropbox** — 폴더를 그 안에 두면 저절로 따라온다.
  가장 손이 덜 간다
* **Git** (GitHub 등) — 고친 내력이 남고 되돌리기 쉽다. 여러 PC 를 오갈
  거라면 이쪽이 낫다
* **USB** — 그냥 복사하면 된다. 영상까지 23MB 다

어느 쪽이든 받은 PC 에서 `START.bat` 만 누르면 똑같이 뜬다.

### 설정도 같이 옮기기

설정은 서버가 아니라 **브라우저**에 남는다. 그래서 폴더를 옮겨도 고른
목소리와 말투는 따라오지 않는다. 파일 한 장으로 옮긴다.

**전에 쓰던 PC** — 설정 → *Περί* 이 사이트 → **설정 내보내기**
→ `settings.json` 이 받아진다.

**새 PC** — 그 파일을 `index.html` 옆에 놓기만 하면 된다.
켤 때 **저절로 적용된다.** 아무것도 누르지 않아도 된다.

```
ktema/
  index.html
  settings.json   ← 여기
  assets/
```

목소리·말투·출처 켜고 끄기·갱신 간격·속보·관심종목·차트 기간이 모두
넘어간다. 읽은 기사 목록은 담지 않는다 — 옮겨 봐야 쓸모가 없다.

한 번 적용하면 그 파일은 다시 심지 않는다. 새 PC 에서 취향을 바꿔도
다음에 켤 때 되돌아가지 않는다는 뜻이다. 설정을 새로 내보내 파일을
갈아 끼우면 (`savedAt` 이 달라지므로) 그때 다시 적용된다.

파일을 폴더에 넣기 번거로우면 설정 화면의 **설정 가져오기** 로 직접
골라도 똑같다.

> 목소리는 **이름으로** 저장된다. 새 PC 에 같은 이름의 목소리가 없으면
> 그 자리는 자동으로 가장 어울리는 목소리로 채워진다.
>
> 웹호스팅에 올릴 때 `settings.json` 을 같이 올리면 **그 사이트에 처음
> 들어오는 모든 사람**에게 그 설정이 심긴다. 혼자 쓸 것이 아니라면
> 올리지 않는 편이 낫다.

> `serve.mjs`·`START.bat`·`start.sh` 는 미리보기 전용이다.
> 웹호스팅에 올릴 때는 아무 일도 하지 않으니 지워도 된다.

### 호스팅 종류별로

| 호스팅 | 할 일 |
|---|---|
| **일반 웹호스팅 (Apache)** | 그대로 올린다. `.htaccess` 가 알아서 맞춘다. PHP 가 되면 `api/proxy.php` 도 같이 살아난다 |
| **Nginx** | `.htaccess` 는 무시된다. `nginx.conf.example` 의 내용을 서버 설정에 옮긴다 |
| **Vercel / Netlify / GitHub Pages** | 폴더째 올리면 된다. PHP 는 돌지 않으므로 공개 프록시를 쓴다 |
| **PHP 없는 정적 호스팅** | `api/` 를 지워도 된다. 사이트가 알아서 공개 프록시로 넘어간다 |

### 용량

영상 열세 편이 약 23MB, 나머지가 1MB 미만이다. 영상은 필요할 때 한 편씩
받고, 나머지는 화면이 뜬 뒤 조용히 받아 둔다. 첫 화면에 필요한 것은 1.6MB
한 편뿐이다.

## 2. 소식은 어디서 오나

각 언론사가 스스로 열어 둔 **공개 RSS** 다. 목록은
[`assets/js/news/sources.js`](assets/js/news/sources.js) 한 곳에 있다.

한국어 — 연합뉴스, 한국경제, 매일경제, 이데일리, 조선비즈, 동아일보, 한겨레
영어 — Yahoo Finance, MarketWatch, WSJ Markets, Financial Times,
Investing.com, Seeking Alpha, Federal Reserve

출처를 더하려면 그 파일의 `SOURCES` 에 한 줄 보태면 된다.

```js
{
  id: 'my-source',            // 안에서만 쓰는 이름표 (바꾸지 말 것)
  name: '내 언론사',            // 화면에 뜨는 이름
  lang: 'ko',                 // ko | en
  weight: 6,                  // 같은 기사가 겹칠 때 누구를 남길지
  url: 'https://…/rss.xml',
  cats: ['econ', 'stock'],    // all·stock·econ·invest·world
}
```

PHP 프록시를 쓰고 있다면 `api/proxy.php` 의 `ALLOW` 에도 그 도메인을 적어야
한다. 적지 않으면 그 출처만 막힌다.

### CORS 를 넘는 방법

브라우저는 남의 도메인에서 RSS 를 곧바로 받아 오지 못한다. 그래서 길을
여럿 두고, 먼저 열리는 길을 그 출처의 길로 기억한다.

```
0. api/proxy.php        이 사이트에 있으면 가장 먼저, 가장 안정적
1. 곧바로                CORS 를 열어 둔 곳 (MarketWatch, Yahoo 뉴스 RSS)
2. 공개 프록시 다섯 곳     나머지 전부
   cors.sh · corsfix · cors.eu.org · allorigins · codetabs
```

설정 → *Περί* 에서 지금 어느 길로 다니고 있는지 볼 수 있다.

> **공개 프록시는 오래 두면 하나씩 문을 닫는다.** 2026년 8월에 다시 두드려
> 보고 목록을 갈아 끼웠다 — corsproxy.io 는 열쇠를 요구하게 되었고,
> api.cors.lol 은 응답하지 않는다. 야후 시세(`query1.finance.yahoo.com`)도
> 예전과 달리 CORS 를 닫아, 이제는 시세도 프록시를 거친다.
>
> 언젠가 이 다섯도 다 막힐 수 있다. 그때는
> [`assets/js/net/proxy.js`](assets/js/net/proxy.js) 의 `ROUTES` 에 살아
> 있는 곳을 한 줄 보태면 된다. 애초에 그런 날을 위해 `api/proxy.php` 가
> 있다 — PHP 가 되는 호스팅에 올려 두면 남의 호의에 기대지 않는다.
>
> 길은 출처마다 따로 배운다. 어떤 프록시는 되돌림(redirect)을 제대로
> 따라가지 못해 한겨레·FT 처럼 주소를 옮기는 곳에서만 넘어지는데, 그런
> 곳은 다음 길이 받아 준다. 그래서 길을 여럿 둔다.

## 3. 자키람

원본 영상 열세 편에서 만들었다. 원본은 816×1104 / 24fps /
15.04초, 편당 약 15MB 였다. 웹에 올리려고 612×828 / CRF 28 로 다시 인코딩해
편당 1.6~2MB 로 줄였다 (소리는 뺐다 — 목소리는 합성으로 낸다).

```bash
ffmpeg -i 1.mp4 -an -vf "scale=612:828:flags=lanczos" \
  -c:v libx264 -preset slow -crf 28 -pix_fmt yuv420p \
  -movflags +faststart assets/media/zakiram/01.mp4
```

### 입이 끊기지 않게 하는 법

열세 편을 표정 조각으로 잘게 썰어 이어 붙이면 입이 튄다. 그래서 반대로 했다.

* 영상 하나를 **4~15초짜리 긴 구간** 단위로만 다룬다 ([`clips.js`](assets/js/zakiram/clips.js))
* `<video>` 를 **두 장 포개** 놓는다. 한 장이 보이는 동안 다른 한 장은 다음
  구간을 미리 열어 그 자리에 세워 둔다
* 넘길 때가 되면 세워 둔 쪽을 재생하고 **불투명도만 0.56초에 걸쳐 바꾼다**.
  검은 화면도, 멈춘 프레임도 없다
* **기분이 바뀌어도 지금 구간은 끊지 않는다.** 아직 안 넘겼으면 세워 둔 것만
  갈아 끼운다. 그래서 읽던 문장의 입 모양이 그대로 이어진다

구간 표를 고치려면 [`clips.js`](assets/js/zakiram/clips.js) 의 `SPANS` 에서
초만 바꾸면 된다. 영상을 갈아 끼울 때도 같다.

| 기분 | 언제 | 쓰는 영상 |
|---|---|---|
| `serene` 고요 | 조용한 시장 | 13, 5, 8, 2 |
| `talk` 평온 | 보통 | 1, 4, 8, 2, 9 |
| `bright` 맑음 | 오르는 쪽 | 3, 4, 11 |
| `elated` 환희 | 넓게 크게 오름 | 11, 3 |

([`mood.js`](assets/js/zakiram/mood.js)).

## 4. 목소리

브라우저에 들어 있는 **Web Speech API** 를 쓴다. 열쇠도 서버도 필요 없고,
기기에 깔린 목소리를 그대로 고를 수 있다.

자키람은 **여성의 목소리**로 말한다. 그런데 규격에는 성별 항목이 없다.
남는 단서는 이름뿐이라 이름표를 들고 가른다 —
[`voices.js`](assets/js/voice/voices.js) 의 표가 그것이다. 여성으로 짚인
목소리만 목록에 올리고(설정에서 끌 수 있다), 스스로 고를 때도 남성으로
짚인 것은 후보에서 뺀다.

설정 → *Φωνή* 에서 한국어·영어 목소리를 **따로** 고르고 하나씩 들어 볼 수
있다.

### 결 일곱 — 같은 목소리, 다른 사람

기기에 여성 목소리가 하나뿐인 일이 흔하다. 그래서 목소리 위에 **결**을
얹는다. 빠르기와 높낮이만 만져도 인상이 꽤 달라진다.

| | 빠르기 | 높낮이 | 언제 |
|---|---|---|---|
| **Σοφία** 지성 | 0.98 | 1.06 | **기본값** — 또박또박, 들뜨지 않게 |
| **Χρησμός** 신탁 | 0.92 | 1.14 | 느리고 조금 높다 |
| **Ἑσπέρα** 그윽함 | 0.90 | 0.94 | 낮고 깊다. 나이가 한 뼘 들어 보인다 |
| **Αἴγλη** 맑음 | 1.02 | 1.20 | 가볍고 밝다 |
| **Γαλήνη** 고요 | 0.86 | 1.02 | 긴 기사를 오래 들을 때 |
| **Ὀξύς** 단호 | 1.06 | 1.18 | 속보와 시세 |
| **Ψίθυρος** 속삭임 | 0.82 | 1.26 | 밤에 조용히 |

기본값이 **지성**이다. 높낮이 1.06 은 그냥 고른 값이 아니다. 영상 열세
편의 소리를 자기상관으로 재어 보니 기본 진동수 중앙값이 184~245Hz,
전체로는 220Hz 언저리였다. 여성 음역이되 들뜨지 않는 자리를 그 안에서
잡았다. 빠르기 0.98 은 읽어 주는 사람의 속도다 — 느리면 굼떠 보이고
빠르면 조급해 보인다.

### 한국어와 영어를 함께

읽을 글이 영어면 영어 목소리로, 한국어면 한국어 목소리로 읽는다. 문제는
**한 문장에 둘이 섞일 때**다.

> Fed 가 금리를 동결했습니다

이것을 한국어 목소리에게 통째로 주면 `Fed` 를 제대로 읽지 못하고, 영어
목소리에게 주면 뒷말이 통째로 무너진다. 그래서 말결대로 잘라 조각마다 그
말을 아는 목소리에게 준다 ([`fmt.js`](assets/js/core/fmt.js) 의 `langRuns`).

```
Fed          → 영어 목소리
가 금리를 동결했습니다  → 한국어 목소리
```

잘게 자를수록 사이가 끊기므로, 세 글자 이상인 라틴 덩이만 건너보낸다.
`Bank of Korea` 처럼 잇닿은 것은 한 숨에 읽는다. 설정 → *Φωνή* 의
**섞인 영어는 영어 목소리로** 로 끌 수 있다.

기기에 한쪽 말의 목소리가 없으면 있는 쪽에게 맡긴다. 발음은 어색해도
조용한 것보다는 낫다.

### 목소리가 하나뿐이라면

윈도우에서 크롬을 쓰면 목소리가 한둘밖에 안 보일 수 있다.

* **엣지(Edge)** 로 열면 `Microsoft … Online (Natural)` 목소리가 여럿 잡힌다.
  훨씬 자연스럽다
* 윈도우 **설정 → 시간 및 언어 → 음성 → 음성 추가** 로 더 깔 수 있다
* 안드로이드는 **설정 → 접근성 → 텍스트 음성 변환** 에서 고른다

## 4-2. 입 모양 — 음소로 푼다

영상 속 입은 지금 읽는 말과 아무 상관이 없다. 열세 편으로 정해져 있으니
어쩔 수가 없다. 그래서 소리가 아니라 **입 모양 쪽을 음소 단위로** 짰다.

```
읽을 글 → 음소 → 입 모양(비짐) → 얼굴 위에 겹쳐 그린다
```

**한글**은 음소가 글자 안에 그대로 들어 있다. 유니코드에서 음절을
초성·중성·종성으로 가르는 셈이 정해져 있어 사전이 필요 없다.

```
(음절 − 0xAC00) = ((초성 × 21) + 중성) × 28 + 종성
```

입을 정하는 것은 거의 중성이다. 초성은 앞에 짧게 얹히고(ㅁ·ㅂ·ㅍ 는 입을
다문다), 종성은 뒤에 짧게 닫는다. `자키람` 은 이렇게 풀린다.

```
자 → ㅈ(좁게) ㅏ(크게)      키 → ㅋ(반쯤) ㅣ(옆으로)
람 → ㄹ(살짝) ㅏ(크게) ㅁ(다문다)
```

**영어**는 철자와 소리가 따로 논다. 사전을 들일 수는 없으니 두 글자
묶음(`sh` `ch` `th` `oo` `ea` …)을 먼저 보고 나머지는 낱자로 본다. 정확한
발음 기호는 아니지만 입 모양을 정하는 데는 넉넉하다.

시간은 합성기가 주는 `boundary` 사건으로 맞춘다. 목소리마다 실제 빠르기가
달라 그냥 두면 뒤로 갈수록 밀리므로, 어긋난 만큼의 삼분의 일씩 끌어당긴다.

그린 것은 입술을 흉내 내지 않는다. **금빛 획 하나**다. 조금만 어긋나도
흉해지는 그림 대신, 말이 지나가는 자리를 빛으로 짚는다.

| 고칠 것 | 어디 |
|---|---|
| 음소를 푸는 규칙 | [`voice/phoneme.js`](assets/js/voice/phoneme.js) |
| 입 모양의 생김새·움직임 | [`zakiram/mouth.js`](assets/js/zakiram/mouth.js) |
| 획의 색과 굵기 | [`css/zakiram.css`](assets/css/zakiram.css) 의 `.zak__mouth` |

설정 → *Χείλη* 에서 끄고 켜거나, 벌어지는 정도와 크기를 바꿀 수 있다.
자리가 얼굴과 어긋나면 **입 자리 맞추기** 를 누르고 자키람의 입 위를
누르면 그 자리로 옮겨 간다. 기본값(가로 74.3%, 세로 70%)은 포스터에서
입술을 재어 잡은 값이다.

> **말하는 낱말과 입이 완전히 같지는 않다.** 음소의 차례와 길이를 따라
> 움직일 뿐, 영상 속 얼굴의 입술이 실제로 그 모양이 되는 것은 아니다.
> 영상이 정해진 열세 편뿐이라 그 이상은 할 수가 없다.

## 6. 시세와 차트

야후 파이낸스만 쓴다. 등록도 열쇠도 필요 없다. 문은 둘이다.

| 문 | 언제 | 무엇이 오나 |
|---|---|---|
| `spark` | 시세판을 채울 때 — **열둘을 한 번에** | 종가 줄과 그 앞 종가 |
| `chart` | 차트 하나를 그릴 때 | 시가·고가·저가·종가·거래량·52주 |

시세판을 종목마다 한 번씩 부르면 첫 화면에서만 서른 번 남짓 프록시를
두드리게 된다. 남의 프록시는 대개 "몇 초에 몇 번" 으로 문턱을 세므로,
그 셈이 차는 순간 마지막에 나간 차트만 홀로 넘어진다 — *소식은 오는데
차트만 안 뜬다* 는 모양이 그것이었다. 그래서 시세판은 `spark` 로 한 번에
묻고, 소식도 [`pool.js`](assets/js/core/pool.js) 로 여섯씩 줄을 세운다.
`spark` 가 막히면 예전처럼 하나씩 묻는 길로 조용히 되돌아간다.

**숫자는 전부 누를 수 있다.** 시세판의 값, 차트 머리의 등락, 아래 지표들,
그리고 차트의 봉 하나하나까지. 누르면 자키람이 그 값을 읽는다.

지켜볼 종목은 [`symbols.js`](assets/js/market/symbols.js) 의 `DEFAULT_WATCH`
에서 바꾼다. 야후 기호를 쓴다 — 한국 종목은 `005930.KS`, 코스닥은 `.KQ`,
지수는 `^KS11` 처럼.

> 시세는 지연될 수 있고 참고용이다. 자키람은 보이는 것을 읽을 뿐,
> 사거나 팔라고 말하지 않는다.

## 6-2. 지표를 만든다

차트에 얹는 줄은 정해져 있지 않다. 틀을 고르고 기간만 정하면 새 지표가
된다. 같은 틀로 여럿 만들 수 있다 — 이동평균 20일과 112일은 다른 지표다.

차트 화면의 **지표** 단추를 누르면 서랍이 펴진다.

| 틀 | 어디에 | 무엇 |
|---|---|---|
| **이동평균** Μέσος | 봉 위에 겹쳐 | 정해진 날수의 종가 평균 |
| **지수이동평균** Ἐκθετικός | 봉 위에 겹쳐 | 최근 값에 더 무게를 준 평균 |
| **볼린저 밴드** Ζώνη | 봉 위에 겹쳐 | 평균에서 표준편차만큼 떨어진 두 줄 |
| **상대강도** Ἰσχύς | 아래 칸에 따로 | 0~100. 오른 날의 힘과 내린 날의 힘 |
| **MACD** Σύγκλισις | 아래 칸에 따로 | 빠른 평균에서 느린 평균을 뺀 것 |
| **거래량** Ὄγκος | 아래 칸에 따로 | 막대는 그날, 줄은 평균 |

상대강도와 MACD 를 봉과 같은 자리에 겹치면 둘 다 못 읽는다 — 코스피는
6900 이고 상대강도는 38 이다. 그래서 값의 단위가 다른 것은 아래 칸에
따로 그린다.

셈하는 곳은 [`indicators.js`](assets/js/market/indicators.js) 한 곳뿐이다.
차트도 여기서 가져다 그리고 전략 시험도 여기서 가져다 판단한다. 두 곳에서
따로 셈하면 눈으로 본 것과 시험한 것이 어긋난다.

만든 것은 이 브라우저에 남는다.

## 6-3. 전략을 시험한다 — `Δοκιμή`

규칙을 짜서 지난 시세에 대어 본다.

```
언제 사나   이동평균 20 이 이동평균 60 을 위로 뚫는다
언제 파나   이동평균 20 이 이동평균 60 을 아래로 뚫는다
지킴이     손절 0% · 익절 0% · 수수료 25bp
```

**먼저 적어 둘 것.** 지난 시세에서 잘 들었다는 것은 앞으로도 그러리라는
뜻이 아니다. 숫자가 좋아질 때까지 규칙을 고치면, 그것은 시장을 배운 것이
아니라 지나간 우연을 외운 것이다. 그래서 성적에는 늘 **“그냥 사서 들고
있었다면”** 이 나란히 붙는다. 그것을 이기지 못하는 전략은 아무것도 아니다.

### 셈하는 규칙

* 신호는 그날 **종가로 판단**하고 **다음 날 시가에 체결**한다.
  같은 날 종가로 사고파는 것은 실제로 할 수 없는 일이다
* **수수료와 미끄러짐을 양쪽에 매긴다.** 이것을 빼면 자주 사고파는 전략이
  실제보다 훨씬 좋아 보인다
* 살 때는 가진 돈을 전부 쓴다. 공매도는 다루지 않는다 — 없으면 쉰다

### 나오는 숫자

총수익 · 연평균 · **최대낙폭**(꼭대기에서 얼마나 내려갔었나) · 사서 보유 ·
**초과**(사서 보유를 얼마나 이겼나) · 매매 횟수와 승률 · 손익비 ·
**시장 체류**(나가 있던 날의 비율). 자산 곡선에는 전략과 사서 보유가
겹쳐 그려지고, 사고판 자리에 점이 찍힌다.

셈은 [`engine.js`](assets/js/backtest/engine.js) 가 한다.

## 6-4. 투자일지 — `Ἡμερολόγιον`

시장에 대한 자기 생각을 적어 두는 자리다.

사람의 기억은 결과에 맞추어 고쳐진다. 오른 뒤에는 “그럴 줄 알았다” 가 되고,
내린 뒤에는 “불안했다” 가 된다. 그날 적어 둔 글만이 그 고침을 막는다.

그래서 이 일지는 **적을 때의 시세를 함께 붙들어 둔다.** 뒷날 그 글을 다시
볼 때 무엇을 보고 그렇게 썼는지가 같이 나와야 한다.

마음 다섯으로 갈라 두었다 — 오름을 본다 · 내림을 본다 · 지켜본다 ·
움직였다 · 배웠다. 이름표(`#반도체`)로 묶고 글로 찾을 수 있다.

이 브라우저에만 남으므로 **내보내기**가 있다. 파일 한 장으로 옮기거나
갈무리해 둔다.

## 6-5. 대화 — `Διάλογος`

자키람의 얼굴 바로 아래에서 묻는다. 묻는 사람은 얼굴을 보면서 묻고,
자키람은 답하면서 입이 움직인다. 창을 따로 띄우면 그 이어짐이 끊긴다.

답은 세 곳으로 나간다.

```
대화창    전문. 여기가 원본이다
말풍선    요지만 (core/summary.js 가 뽑는다)
목소리    소리. 꺼 두었으면 건너뛴다
```

### 어디에 잇나

| 길 | 무엇 |
|---|---|
| **잇지 않음** Αὐτός | 기본값. 바깥에 잇지 않고 지금 화면의 시세와 소식만 보고 답한다. 열쇠도 값도 들지 않는다 |
| **Claude** | `api.anthropic.com` |
| **GPT** | `api.openai.com` |
| **Grok** | `api.x.ai` |
| **내 서버** Δίοδος | 열쇠를 브라우저에 두지 않는 길 |

설정 → *Διάλογος* 에서 고르고 열쇠를 넣는다.

> **열쇠를 브라우저에 두는 일에 대하여.** 이것은 안전한 방식이 아니다.
> 브라우저에 둔 열쇠는 그 기기를 쓰는 사람이면 누구나 꺼내 볼 수 있고,
> 이 페이지에 끼어든 다른 스크립트도 읽을 수 있다. **혼자 쓰는 기기에서,
> 한도를 걸어 둔 열쇠로** 쓰기를 권한다.
>
> 열쇠는 **설정 내보내기에 담기지 않는다** — `settings.json` 은 폴더에
> 놓거나 웹호스팅에 올릴 수 있는 파일이라, 열쇠가 그 안에 있으면 올리는
> 순간 아무나 읽는다. 옮길 때는 새 기기에서 다시 넣으면 된다.
>
> **여러 사람이 보는 사이트라면 열쇠는 서버 뒤에 두어야 한다.** 그것이
> ‘내 서버’ 길이다. 그 서버는 `{ system, messages }` 를 받아 `{ text }` 를
> 돌려주면 된다. 열쇠는 그 서버가 들고 있으므로 브라우저에는 없다.

자키람이 무엇을 보고 답하는지도 함께 보낸다 — 지금 받아 둔 시세와 소식
제목이다. 이것이 없으면 모형은 오늘 시장을 모른 채 그럴듯한 값을 지어낸다.
지어낸 값은 시장의 말로는 가장 나쁜 것이다.

## 7-2. 무언가 안 보일 때 — `진단.html`

사이트를 띄운 상태에서 `http://localhost:4488/진단.html` 을 연다.
모듈을 하나도 불러오지 않고 혼자 도는 페이지라, 본 사이트가 고장 나
있어도 뜬다. 다섯 가지를 검사한다.

| | 무엇을 보나 |
|---|---|
| 환경 | 브라우저, 창 크기, `file://` 로 연 것은 아닌지, 동작 줄이기 설정 |
| 영상 파일 | 열세 편이 다 있는지, 서버가 형식을 바르게 알려 주는지 |
| 영상 재생 | 읽히는지, **실제로 그림이 나오는지**(픽셀을 떠서 확인), 자동 재생이 되는지 |
| 목소리 | 몇 개인지, 한국어가 있는지, 여자 목소리가 있는지 |
| 바깥 연결 | 시세와 소식이 받아지는지, **어느 길로** 받아지는지 (본 사이트와 같은 차례로 두드려 본다) |

맨 아래 상자의 내용을 복사해 보내면 무엇이 문제인지 바로 드러난다.

### 자키람이 안 보이거나 안 움직인다면

가장 흔한 원인 순서대로.

1. **관문(ΕΙΣΟΔΟΣ)을 아직 안 지났다.** 자키람은 관문 뒤에 있다
2. **자동 재생이 막혔다.** 자키람 자리에 *Ἔγειρε — 화면을 한 번 눌러
   주십시오* 가 뜬다. 아무 데나 한 번 누르면 깨어난다
3. **영상 파일이 덜 풀렸다.** 진단의 *영상 파일* 항목이 알려 준다
4. **하드웨어 가속 문제.** 진단이 "영상이 검게 나옵니다" 라고 하면
   브라우저 설정에서 하드웨어 가속을 꺼 보라

> **영상 속 입술은 낱말에 맞춰 움직이지 않는다.** 원본이 정해진 열세
> 편뿐이라 임의의 문장에 맞출 수가 없다. 대신 얼굴 위에 **음소로 푼 입**을
> 겹쳐 그린다 — 4-2 장을 보라. 그 획이 엉뚱한 자리에 떠 있으면
> 설정 → *Χείλη* 에서 **입 자리 맞추기** 로 옮기면 된다.

## 9. 알아 둘 것

* **설정은 이 브라우저에만 남는다.** 서버가 없으니 계정도 없다.
  사생활 보호 창에서는 저장되지 않는다
* **기사 전문은 담지 않는다.** RSS 가 준 제목과 요약까지만 보이고,
  자키람이 읽는 것도 거기까지다. 전문은 원문 링크로 간다
* **공개 프록시는 남의 호의로 돈다.** 느리거나 멎을 수 있다.
  오래 쓸 거라면 `api/proxy.php` 가 되는 호스팅을 권한다
* 브라우저는 사람이 한 번 눌러 주기 전에 소리를 내지 못한다.
  관문이 그 첫 누름을 받는 자리다
